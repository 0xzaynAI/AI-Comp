## 想法模板

每个想法文档应包含：

```markdown
# [想法名称]

- **来源分析**：基于哪份 01-04 报告
- **目标用户**：谁会付钱
- **核心痛点**：解决什么问题
- **产品形态**：Web App / 小程序 / API / 服务
- **变现方式**：订阅 / 一次性 / 交易抽成
- **竞品分析**：已有玩家及差异点
- **MVP 范围**：最小可行版本包含什么
- **下一步**：验证计划
```
