# 模块 01 — 摆摊经济学：生意的原子单位

> 如果你理解了一个路边摊怎么赚钱，你就理解了世界上所有生意的 80%。

---

## 0. 为什么从摆摊开始学？

摆摊是商业的**原子单位**：

| 生意的本质组件 | 在摆摊里怎么体现 |
|--------------|----------------|
| 产品 | 你卖的那碗炒粉 / 那条数据线 |
| 供应链 | 批发市场、1688、拼多多 |
| 定价 | 8 块还是 10 块？定价决定生死 |
| 选址 = 流量 | 地铁口 vs 小区门口，差 10 倍销量 |
| 成本结构 | 食材 + 摊位费 + 交通 |
| 毛利率 | 这碗粉赚多少？ |
| 现金流 | 今天卖了多少钱？还剩多少货？ |
| 竞争 | 旁边还有两个摊，凭什么买你的？ |

所有的大生意，本质都是**无数个「原子单位」的叠加和优化**。麦当劳 = 3 万个标准化摆摊点。

## 1. 毛利率：生意的第一性原理

### 1.1 定义

```
毛利率 = (售价 - 进货成本) / 售价 × 100%
```

**不是** (售价 - 进货成本) / 进货成本。很多人搞反。

### 1.2 摆摊实例

你摆摊卖手机壳：

| 项目 | 金额 |
|------|------|
| 进货价 | 3 元/个 |
| 售价 | 15 元/个 |
| 毛利 | 12 元 |
| 毛利率 | 12/15 = **80%** |

80% 毛利率什么概念？奢侈品水平。但别急着高兴——

### 1.3 毛利率 vs 净利率

毛利率只扣了**货的成本**，没扣**其他一切**：

| 项目 | 日金额 |
|------|--------|
| 卖 20 个手机壳，营收 | 300 元 |
| 进货成本 (20 × 3) | 60 元 |
| **毛利** | 240 元 (毛利率 80%) |
| 摊位费 | 50 元/天 |
| 交通+吃饭 | 40 元 |
| **净利** | **150 元** (净利率 50%) |

> ⚠️ **第一条教训**：毛利率高 ≠ 赚钱。当其他成本（摊位费、人力、物流）占比大时，高毛利也能亏钱。

### 1.4 不同品类的毛利率基准

| 品类 | 典型毛利率 | 说明 |
|------|----------|------|
| 小吃/餐饮 | 60-70% | 食材便宜，但人工和租金高 |
| 服装/饰品 | 70-85% | 暴利行业，但库存风险大 |
| 手机配件 | 80-90% | 进货极便宜，靠走量 |
| 生鲜/蔬菜 | 20-35% | 损耗率决定生死 |
| 奶茶 | 70-80% | 毛利高，但竞争激烈 |
| 书籍 | 30-40% | 毛利低，定价透明 |

> 🔑 **第二条教训**：毛利率低于 30% 的生意慎入——你没有容错空间。一次雨天、一次压货，就可能亏钱。

## 2. 供应商：进货的学问

### 2.1 去哪找货源

| 渠道 | 适合品类 | 优缺点 |
|------|---------|--------|
| 1688.com | 几乎所有 | 便宜但要自己筛选，有假货 |
| 拼多多 | 小件、日用品 | 价格透明、一件代发 |
| 本地批发市场 | 服装、饰品、食品 | 能看货摸货、可谈价 |
| 义乌购 | 小商品 | 品类全，起订量低 |
| 微信/抖音商家 | 潮品、网红款 | 跟风快，但质量不稳 |
| 咸鱼/二手 | 特定品类 | 极度便宜，但不稳定 |

### 2.2 怎么跟供应商谈

第一次进货的黄金法则：

```
1. 别说「我是摆摊的」→ 说「我先拿点样品，好卖的话长期拿」
2. 问清楚最小起订量 (MOQ)
3. 问批发价：拿 10 个什么价？50 个什么价？100 个什么价？
4. 拿样：先买 1-2 个回去看质量，再决定批量进货
5. 比价：1688 上同样的东西搜 3 家对比
6. 问退换政策：质量有问题能退吗？
```

> 🔑 **第三条教训**：供应商不看你卖多少，只看你拿多少。**拿货量大就有议价权**。一个摊贩永远没有议价权——这就是为什么你要动脑子做差异化，而不是比谁进货便宜。

### 2.3 进货的天坑

- **看图片下单** → 收到完全不一样的东西（必须看实物）
- **囤货过多** → 卖不掉全砸手里（首单宁少勿多）
- **赊账进货** → 供应商给你赊账说明货不好卖
- **只用一个供应商** → 断了你就死了

## 3. 选址 = 流量

### 3.1 流量公式

```
日营收 = 路过人数 × 驻足率 × 购买转化率 × 客单价
```

| 变量 | 地铁口 | 小区门口 | 夜市 |
|------|--------|---------|------|
| 路过人数 | 5000/天 | 500/天 | 2000/天 |
| 驻足率 | 2% | 10% | 8% |
| 有驻足的人 | 100 | 50 | 160 |
| 购买转化率 | 15% | 30% | 25% |
| 成交数 | 15 单 | 15 单 | 40 单 |
| 客单价 | 12 元 | 15 元 | 20 元 |
| **日营收** | **180 元** | **225 元** | **800 元** |

> 🔑 **第四条教训**：夜市虽然路过人数不如地铁口，但驻足率和客单价更高——因为大家是**带着消费意愿来的**。地铁口的流量是**赶路的流量**，转化率低。

### 3.2 选位置的核心问题

到现场蹲 2 小时，回答以下问题：

1. 这条街现在有几个摆摊的？卖什么？
2. 路过的都是什么人？（上班族/学生/大爷大妈/带娃的？）
3. 他们走路快不快？（快 = 不会停下来买）
4. 有没有城管？（有 = 随时要跑）
5. 旁边商铺生意怎么样？
6. 同品类的摊有几个？他们的东西卖多少钱？

> 💡 如果你旁边已经有一个卖同样东西的摊，你要么卖**不一样的东西**，要么**比他便宜**，要么**比他好吃/好用**。三样都不占，就换地方。

## 4. 现金流：比你想象的更重要

### 4.1 现金流的本质

```
进货花 1000 元 → 摆摊卖了 1500 元 → 赚了 500 元

但是：
第一天：进货 1000 元（现金 -1000）
第二天：卖了 800 元（现金 -200）
第三天：卖了 700 元（现金 +500）
```

**你的 1000 块被锁在货里了两天。**

### 4.2 压货 = 死缓

| 场景 | 进货 100 个 | 进货 30 个 |
|------|------------|-----------|
| 进价/个 | 3 元 | 3.5 元 |
| 总投入 | 300 元 | 105 元 |
| 日销 10 个 | 10 天卖完 | 3 天卖完 |
| 卖不完的风险 | 剩余 70 个 = 210 元打水漂 | 更容易卖完 |

> 🔑 **第五条教训**：**进货量 × 销售周期 = 你的风险敞口**。新手宁可贵一点少拿点，也别为了便宜大量囤货。现金流断了，游戏结束。

### 4.3 算一笔完整的账

摆摊卖手打柠檬茶：

| 项目 | 月金额 |
|------|--------|
| 营收 (30 杯/天 × 10元 × 30天) | 9,000 元 |
| 原料成本 (柠檬+茶+糖+杯) 3元/杯 | -2,700 元 |
| **毛利 (毛利率 70%)** | **6,300 元** |
| 冰块 | -200 元 |
| 摊位费 | -1500 元 |
| 交通 | -200 元 |
| 设备摊销 (推车+保温箱) | -300 元 |
| **月净利** | **4,100 元** |

> 这还没算你的时间。按 30 天每天 5 小时 = 150 小时，时薪 = 4,100 / 150 = **27 元/小时**。
>
> 比深圳最低工资高，但不多。这就叫**辛苦钱**。

## 5. 从摆摊学到的商业真理

### 5.1 六条铁律

1. **毛利率是你唯一的缓冲垫**。毛利率低于 50%，一次坏天气你就亏钱。
2. **选址决定 70% 的销量**。同样的产品，不同位置差 5-10 倍。
3. **现金流 > 利润**。账上有利润但手里没钱 = 死。
4. **速度快过完美**。卖得动的东西马上补货，卖不动的马上清仓。别犹豫。
5. **熟客 = 稳定的现金流**。一个每天买你东西的老客户，价值远超一个路过的。
6. **谁都能做的生意不是好生意**。如果任何人都能支个摊卖一样的东西，你的利润很快会被竞争清零。

### 5.2 这条铁律向上生长

摆摊的每一条教训，往上走完全适用：

| 摆摊 | 小店 | 连锁 | 上市企业 |
|------|------|------|---------|
| 毛利率 | 毛利率 | 毛利率 | 毛利率 |
| 选址 | 选址 | 选址 | 门店模型 |
| 进货价 | 供应商谈判 | 供应链优化 | 全球采购 |
| 熟客 | 会员 | CRM 系统 | 用户留存率 |
| 卖不完清仓 | 促销 | 库存周转率 | 资产周转率 |

**你在地摊上没搞懂的东西，到上市公司你还是搞不懂。**

## 练习题

1. 去你家楼下找一个摆摊的（卖小吃的、卖水果的、贴膜的都可以），估算他的：
   - 日营收、日毛利、日净利
   - 毛利率、净利率
   
2. 去 1688.com 搜「手机壳」，找出 3 款，算出如果你在夜市卖 15 元一个，毛利率分别是多少。

3. 假设你要在楼下摆摊卖烤肠：
   - 火腿肠进价 0.8 元/根，竹签忽略不计，煤气+调味料 0.2 元/根
   - 售价 3 元/根
   - 每天卖 100 根，出摊 25 天
   - 摊位费 800 元/月
   - 交通+杂费 200 元/月
   
   请问：月营收？月毛利？毛利率？月净利？时薪（按每天 4 小时算）？

4. **思考题**：你楼下的摊位里，哪个赚最多？为什么？用今天学到的所有概念分析。
