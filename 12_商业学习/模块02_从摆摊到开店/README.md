# 模块 02 — 从摆摊到开店：固定成本的赌局

> 摆摊 = 灵活但赚辛苦钱。开店 = 能赚更多，但你签了一份「每月先亏 X 万」的合同。
> 
> 开店不是「摆摊的升级版」，它是完全不同的游戏。

---

## 1. 摆摊 vs 开店：本质区别

| 维度 | 摆摊 | 开店 |
|------|------|------|
| 固定成本 | 几乎为零（不摆摊就不花钱） | 每月必须付，不营业也付 |
| 收入上限 | 受限于自己的时间 | 雇人后理论上无限 |
| 试错成本 | 零（今天卖不动明天换品类） | 高（装修完就回不了头） |
| 城管关系 | 躲着走 | 供着走（消防、工商、卫生） |
| 顾客信任 | 低（随时跑路） | 高（跑得了和尚跑不了庙） |
| 规模化 | 不可能 | 可能（开分店） |

> 🔑 **第一条铁律**：开店前，先问自己——「我摆摊的月净利，能覆盖店铺租金的 **3 倍** 吗？」如果不能，别开。

为什么是 3 倍？因为租金只占固定成本的 1/3 左右。剩下的是人工、水电、装修折旧、杂费。

---

## 2. 固定成本：你签的那份「每月必须付」的合同

### 2.1 什么叫固定成本？

不管你卖不卖东西、开不开门，**每个月必须付的钱**：

| 项目 | 深圳普通街区 15㎡小店 | 商场 30㎡ |
|------|---------------------|----------|
| 租金 | 8,000 元/月 | 25,000 元/月 |
| 物业+水电 | 1,500 元 | 4,000 元 |
| 人工（1人） | 6,000 元 | 7,000 元 |
| 装修摊销 | 1,500 元（8万÷5年÷12月） | 3,300 元（20万÷5年÷12月） |
| 杂费（耗材、网络等） | 500 元 | 1,000 元 |
| **每月固定成本** | **17,500 元** | **40,300 元** |

> 也就是说，不管你开不开门、卖不卖东西，每个月 **17,500 元** 已经花出去了。

### 2.2 算一笔账：奶茶店

深圳街头 15㎡ 奶茶店：

| 项目 | 月数据 |
|------|--------|
| 月固定成本 | 17,500 元 |
| 每杯奶茶均价 | 15 元 |
| 原料成本 / 杯 | 4.5 元（毛利率 70%） |
| 每杯毛利 | 10.5 元 |
| **盈亏平衡杯数** | **17,500 / 10.5 = 1,667 杯/月** |
| **每天必须卖出** | **56 杯** |

> 56 杯/天是什么概念？按营业 12 小时算，每小时卖出 4.7 杯，每 13 分钟来一个人买。

如果旁边新开了另一家奶茶店，你每天只卖 40 杯呢？

| 场景 | 数值 |
|------|------|
| 月销量 | 40 杯 × 30 天 = 1,200 杯 |
| 月毛利 | 1,200 × 10.5 = 12,600 元 |
| 月固定成本 | 17,500 元 |
| **月净利** | **-4,900 元（亏钱！）** |

> 🔑 **第二条铁律**：开店之后，销量下降 20%，你马上从赚钱变亏钱。摆摊没有这个问题——卖不动今天少赚点，不开张也不亏。

## 3. 坪效：每平米是资产还是负担

### 3.1 定义

```
坪效 = 月营收 / 店铺面积（㎡）
```

| 店铺类型 | 面积 | 月营收 | 坪效 |
|---------|------|--------|------|
| 奶茶店 | 15㎡ | 45,000 | 3,000 元/㎡ |
| 便利店 | 40㎡ | 120,000 | 3,000 元/㎡ |
| 火锅店 | 150㎡ | 200,000 | 1,333 元/㎡ |
| 早餐店 | 10㎡ | 30,000 | 3,000 元/㎡ |
| 服装店 | 50㎡ | 60,000 | 1,200 元/㎡ |

### 3.2 坪效的残酷真相

看两个不同位置的奶茶店：

| | 旺铺（地铁口） | 偏铺（巷子里） |
|------|------|------|
| 面积 | 15㎡ | 15㎡ |
| 月租金 | 15,000 | 5,000 |
| 月固定成本 | 25,000 | 14,000 |
| 日销量 | 150 杯 | 30 杯 |
| 月毛利 | 47,250 | 9,450 |
| 月净利 | **22,250** | **-4,550** |
| 坪效 | 3,150 元/㎡ | 630 元/㎡ |

> 🔑 **第三条铁律**：多付 1 万的租金可能多赚 2 万，少付 1 万租金可能亏 4 千。**租金不是越便宜越好，要看流量。**

## 4. 雇第一个人：最难的一步

### 4.1 为什么要雇人

你自己开店，一天站 12 小时，月净利 22,250 元。

时薪 = 22,250 / (30天 × 12小时) = **62 元/小时**

——不错。但你没有休息日。没有假期。不能生病。不能离开深圳。

### 4.2 雇人后的账

| 项目 | 自己干 | 雇 1 人 |
|------|--------|---------|
| 月净利 | 22,250 元 | 22,250 元 |
| 人工成本 | 0 | -7,000 元 |
| **调整后净利** | **22,250 元** | **15,250 元** |

你的利润少了 7,000。但你每周多了 40 小时自由时间。这些时间你可以：
- 开第二家店
- 拓展线上渠道
- 陪家人
- 什么都不干

> 🔑 **第四条铁律**：雇人不是成本，是**杠杆**。让你的时间从「做奶茶」变成「管店」，单位时间价值从 62 元变成无限大。

### 4.3 雇人的坑

| 坑 | 怎么办 |
|----|--------|
| 员工偷懒/偷钱 | 必须装监控，每天自己盘账 |
| 手艺不稳定 | 写 SOP（标准化流程），每种茶多少克、泡几分钟 |
| 忽然离职 | 你随时能顶上（开第一家店时别想着全脱手） |
| 招不到人 | 薪资别抠，好员工值这个价 |

## 5. 开店的死亡陷阱（只有 20% 的新店活过 2 年）

### 陷阱 1：「摆摊赚了钱，开店肯定也赚」

摆摊烤肠月赚 4,000 → 觉得开店能赚 10,000。

但开店的成本结构完全不同。你在摆摊上验证的只是「这个产品有人买」，没有验证「这个产品能覆盖固定成本」。

### 陷阱 2：「装修好一点，顾客就来了」

顾客进来是因为**位置**和**产品**，不是因为装修。

见过太多店：装修花了 15 万，三个月关门，装修 8 折都没人要。

> 🛑 **先验证产品和位置，再考虑装修。** 开业前三个月不做大装，先试营业。

### 陷阱 3：「加盟 = 稳赚」

加盟的本质是：**品牌方把风险转嫁给你，自己稳赚加盟费**。

| 加盟商说的 | 真实意思 |
|-----------|---------|
| 「总部全程扶持」 | 交钱后你自己想办法 |
| 「回本周期 6-8 个月」 | 按最好单店数据算，不保证 |
| 「区域保护，3 公里内不放开第二家」 | 3 公里外还有 20 个加盟商在抢 |
| 「供应链成熟，进货便宜」 | 必须从总部进货，价格比市场贵 20% |

> 🔑 如果你真想加盟，先去那个品牌已有的 3 家加盟店门口**蹲一天**，数人流、算营收。不要听品牌方的，看真实的。

### 陷阱 4：「再坚持一下就好了」

每月净亏 5,000 元，总觉得「下个月会好」。

> 🛑 **设一个止损线**：连续亏损 3 个月就关。不要用「再熬一熬」骗自己。

## 6. 什么时候可以从摆摊升级到开店？

满足**全部三项**再考虑：

- [ ] 你的摊位连续 6 个月月净利稳定（不是某个月爆单）
- [ ] 月净利 ≥ 预计开店月固定成本 × 1.5
- [ ] 你知道现在来找你的熟客有多少（证明你的产品有复购，不只是过路生意）

> 💡 黄金代购的启示：不是所有生意都需要开店。有些生意天生就是「无店铺」模式——服务类、代购类、线上类。开不店不是成功的标准，**赚钱才是**。

## 7. 一个真实的小店损益表

深圳城中村 20㎡ 肠粉店：

| 项目 | 月金额 |
|------|--------|
| **营收** | |
| 肠粉 (80份/天 × 8元 × 30天) | 19,200 元 |
| 豆浆/粥（搭配销售） | 3,000 元 |
| 月总营收 | **22,200 元** |
| | |
| **变动成本** | |
| 食材（米浆+肉+蛋+菜） | 6,600 元 |
| 打包盒+酱料 | 800 元 |
| | |
| **固定成本** | |
| 租金 | 5,500 元 |
| 水电 | 800 元 |
| 人工（夫妻店，不拿工资但这是机会成本） | — |
| 设备折旧 | 300 元 |
| | |
| **月净利润** | **8,200 元** |
| **净利率** | **37%** |

> 两个人，每天凌晨 4 点到下午 2 点，月赚 8,200 元。人均 4,100 元/月。
>
> 这就是大部分夫妻小店的真实利润。不多，但稳定。

## 练习题

### 第 1 题：算盈亏平衡

你在深圳想开一家 15㎡ 奶茶店：
- 租金 10,000/月
- 人工 7,000/月（你自己不拿工资，但你雇一个人）
- 水电杂费 1,500/月
- 装修分摊 2,000/月
- 每杯奶茶均价 18 元，原料成本 5 元

请问：
1. 月固定成本是多少？
2. 每杯毛利是多少？
3. 每月要卖多少杯才盈亏平衡？
4. 每天（30 天）要卖多少杯？

### 第 2 题：决策判断

你的肠粉摊已经摆了 8 个月，情况如下：
- 每天早上 6:00-10:00 出摊，卖 70-90 份肠粉（平均 80 份）
- 每份卖 8 元，原料成本 3 元
- 摊位费 600 元/月，交通杂费 300 元/月
- 月净利约 7,100 元

旁边有个 15㎡ 店铺，月租 6,000 元。要不要租下来开店？

用今天学到的框架分析。

### 第 3 题：坪效排序

以下四家店，哪家坪效最高？
- A. 10㎡ 奶茶店，月营收 30,000 元
- B. 50㎡ 服装店，月营收 60,000 元
- C. 100㎡ 火锅店，月营收 200,000 元
- D. 8㎡ 彩票店，月营收 32,000 元
