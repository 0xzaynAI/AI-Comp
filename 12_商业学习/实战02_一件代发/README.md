# 实战 02 — 一件代发：你的假设错在哪里

> 你说：选品 → 开矩阵店 → 等客源。前两步对了一半，第三步全错。

---

## 一、先确认：什么叫「一件代发」？

```
你在平台A开店 → 客户下单 → 你去平台B（1688/拼多多）下单 
→ 平台B商家发货给客户 → 你赚差价
```

**你的角色**：一个不碰货的中间商。

**利润公式**：
```
利润 = 售价 - 进货价 - 平台佣金 - 广告费 - 退款损耗
```

---

## 二、逐条核对你的假设

### 假设 ①：「不需要开店」

| 平台 | 真相 | 判定 |
|------|------|------|
| **闲鱼** | 不用开店，个人账号即可。但一个身份证只能实名 **1-3 个**账号，且平台在严打无货源。 | ⚠️ 半对 |
| **拼多多** | 要开店。个人店保证金 **2,000 元起**，要身份证+手机号。每张身份证能开多个店但需要不同手机号。 | ❌ 要开店 |
| **抖音** | 要开抖店。需要**营业执照**（个体户或公司）+ 保证金 **2,000-10,000 元**不等。 | ❌ 要开店 |

> 🔑 三个平台里，闲鱼最接近你说的「不开店」，但也限制最多、封号风险最大。

---

### 假设 ②：「只需要做好选品」

选品确实最重要，占成功因素的 **50%**。

还有 50% 是什么？

| 环节 | 重要性 | 说明 |
|------|--------|------|
| 选品 | ★★★★★ | 选什么类目？什么价位？有什么差异化？ |
| **标题优化** | ★★★★ | 包含什么关键词？怎么让搜索排名靠前？ |
| **主图** | ★★★★ | 第一张图决定点不点进来 |
| **定价** | ★★★★ | 太低没利润，太高没人买 |
| **客服** | ★★★ | 回复速度影响转化率 |
| **售后** | ★★★ | 退款、差评处理 |
| **平台规则** | ★★★★★ | 违规 = 封店，前面全白做 |

> 🔑 选品是弹药，但**怎么把这颗子弹打出去**才是完整的生意。

---

### 假设 ③：「多开矩阵店铺」

理论上可行，实际操作有三道坎：

| 坎 | 闲鱼 | 拼多多 | 抖音 |
|----|------|--------|------|
| 身份限制 | 1人最多3号 | 1人可多店（需多手机号） | 1个营业执照1店 |
| 管理成本 | 多个号轮流擦亮、回复 | 多店需要ERP软件（月费几百） | 多店 = 多套资质 + 多套运营 |
| 平台打击 | **严打无货源**，封号连带 | 打击重复铺货、店群 | 打击无货源 |

> 🔑 「先开 10 个店，每个每天出一单」——这是 2019 年的玩法。现在平台算法能识别同一人开的多个店，一锅端。

---

### 假设 ④：「等客源」 ← 最大的错误

**没有一个平台会主动给你流量。** 这是你理解里最需要纠正的一点。

| 平台 | 流量怎么来 |
|------|-----------|
| **闲鱼** | 需要每天**擦亮**、降价、优化标题；平台给新发布商品 24 小时流量窗口 |
| **拼多多** | 要么**最低价**（自然排名），要么**投广告**（多多搜索/场景），或者两个都要 |
| **抖音** | 要么**拍短视频/直播**引流，要么做**商品卡**优化（标题+主图+价格+销量） |

> 🔑 你理解的模式是「开店 → 上架 → 来人买」。现实的模式是「开店 → 上架 → **持续运营 → 持续投流 → 持续优化** → 来人买」。

---

## 三、三个平台详细拆解

### A. 闲鱼一件代发

**模式**：在拼多多/1688找低价品 → 加价挂闲鱼 → 有人买就去上家下单

**优点**：
- 零门槛，有手机就能开始
- 零保证金
- 每个商品发布后有 24 小时流量窗口

**现实问题**：

| 问题 | 严重度 | 说明 |
|------|--------|------|
| 封号 | 🔴 高 | 闲鱼是二手平台，不是电商平台。批量上新货 = 违规。大量发货地址对不上 = 封号。 |
| 价格透明 | 🔴 高 | 买家截图去拼多多搜，发现便宜一半 → 退款/差评 |
| 物流轨迹 | 🟡 中 | 上家从义乌发货，你说你在深圳 → 买家质疑 |
| 售后纠纷 | 🟡 中 | 退货你退给谁？上家不退怎么办？ |

**2025 年还能做吗？**

可以做，但不再是「批量铺货等客源」的模式。现在活下来的都是 **精细化运营**：
- 精选 20-30 个品，每个写好标题和描述
- 主图自己拍或用差异化图片（不要直接用上家的图）
- 每天擦亮、互动
- 选有信息差的品类（买家搜不到的偏门货）

---

### B. 拼多多一件代发

**模式**：从 1688 选品 → 加价上架拼多多 → 用户下单 → 去 1688 下单 → 1688 发货

**优点**：
- 个人身份证就能开店
- 拼多多用户基数大
- 价格敏感型用户多，低价有机会

**现实问题**：

| 问题 | 严重度 | 说明 |
|------|--------|------|
| 价格战 | 🔴 极高 | 同样产品，人家比你便宜 1 块，你就没单 |
| 广告费 | 🔴 高 | 不投广告 ≈ 没流量。投产比（ROI）控制不好 = 亏钱 |
| 仅退款 | 🔴 高 | 拼多多「仅退款」政策，买家退款你不一定拿回货。损失你承担 |
| 罚款 | 🟡 中 | 物流超时、回复慢、DSR 评分低 = 罚款 |
| 利润薄 | 🔴 高 | 加价 5-10 元/单，但广告费吃掉 3-8 元，净利可能只有 2-3 元 |

**店群模式还成立吗？**

2025 年拼多多也在收紧：
- 淘宝已经直接封杀无货源店群
- 拼多多虽然还没禁，但流量向品牌和有货源商家倾斜
- 店群需要 ERP 软件（月费 200-500），管理成本不低

---

### C. 抖音小店一件代发

**模式**：从抖音官方供应链平台选品 → 一键上架 → 用户下单 → 供应商自动发货 → 自动分账

**这是三个平台里最适合新手的。** 原因：

| 优势 | 说明 |
|------|------|
| 官方供应链 | 抖音自建分销平台，供应商经过审核，不用自己去 1688 找 |
| 自动发货 | 订单自动推给供应商，不需要手动拍单 |
| 自动分账 | 订单完成后利润自动到账 |
| 商品卡免佣 | 非直播/短视频出单，平台免技术服务费 |
| 竞争相对小 | 比淘宝拼多多晚起步，还有窗口期 |

**但是——还是要运营：**

| 你必须做的 | 为什么 |
|-----------|--------|
| 选品 | 选「销量高但达人带货少」的品 → 说明是商品卡自然流量出单 |
| 定价 | 上架价设为进货价 × 2，然后用折扣打到 4.2-4.9 折 |
| 每天上新 | 商品卡流量的核心是**持续上新**，一天上 10-20 个品 |
| 优化主图标题 | 影响搜索和推荐排名 |
| 保证金 | 个体店 2,000 元起 |

---

## 四、三平台对比总结

| 维度 | 闲鱼 | 拼多多 | 抖音 |
|------|------|--------|------|
| 门槛 | ★☆☆ 最低 | ★★☆ 要保证金 | ★★★ 要执照+保证金 |
| 流量获取 | 靠擦亮+搜索 | 靠低价/广告 | 靠商品卡优化 |
| 利润空间 | 中（信息差） | 低（价格战） | 中-高（窗口期） |
| 封号风险 | 🔴 高 | 🟡 中 | 🟢 较低（走官方供应链） |
| 适合谁 | 偏门品类、精细化运营 | 有价格优势的货源 | 新手入门、矩阵运营 |
| 能「等客源」吗？ | ❌ 不能 | ❌ 不能 | ❌ 不能 |

## 五、如果用摆摊经济学框架看

| 摆摊 | 一件代发 |
|------|---------|
| 你站在路边 | 你的店铺陈列在搜索结果里 |
| 路过 = 搜索到 | 驻足 = 点进来 |
| 吆喝 = 标题关键词 | 摊位位置 = 搜索排名 |
| 城管 = 平台规则 | 下雨 = 流量波动 |

**摆摊你要选位置、喊吆喝、招呼客人。一件代发也一样——你只是把摊位从马路搬到了手机屏幕里。**

没有人会在巷子最深处摆摊然后「等客源」。搜索结果第 5 页 = 巷子最深处。

## 六、修正后的认知

| 你原来想的 | 修正后 |
|-----------|--------|
| 不需要开店 | 闲鱼最接近，拼多多和抖音都要 |
| 只需要选品 | 选品 50% + 运营 50% |
| 多开矩阵店铺 | 可以做但要合规，不是铺货 |
| **等客源** | **没有平台会白送流量，必须持续运营** |

---

## 七、如果现在开始，推荐路线

```
第 1 步：抖音一件代发（最正规，官方支持）
  ↓
  跑通 1 个店 → 日销 10 单 → 日销 30 单
  ↓
第 2 步：复制到第 2-3 个店（矩阵）
  ↓
第 3 步：闲鱼作为辅助渠道（精细化选品，不做铺货）
  ↓
第 4 步：拼多多只在你找到独家低价货源后再做（否则拼不过价格战）
```

> 🔑 **抖音商品卡 = 2025 年的一件代发最佳入口。** 不需要拍视频、不需要直播、不需要投流，但需要**每天选品上新**。这依然是运营，不是「等」。

## 练习题

1. 你原来的理解有四条假设，修正后各是什么？用自己的话写出来。

2. 打开抖音，搜索「手机壳」，看看商品卡（非直播、非短视频的搜索结果页展示的商品），观察：
   - 排名前 5 的商品有什么共同点？（标题、价格、销量、主图）
   - 如果你是卖家，你怎么让你的手机壳排进前 5？
   
3. 去 1688.com 搜一个你想卖的品类（比如收纳盒、手机支架、袜子），找到 3 款你觉得能加价卖的产品。记录：
   - 1688 进价
   - 你打算卖多少钱
   - 毛利率多少
   - 搜一下抖音/拼多多上同款卖多少钱——你还敢加价吗？
