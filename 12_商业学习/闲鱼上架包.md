# 闲鱼上架包 — 复制粘贴即上架

> 目的：把「上架第一个商品」的所有摩擦降到零。你只需要 3 个动作：打开闲鱼 → 复制 → 发布。
> 第一个商品的目标**不是赚钱**，是拿一周真实数据（曝光 / 咨询 / 成交），验证「你到底能不能下场」。

---

## 方案 A：闲置物品（推荐第一个商品）

### 标题（三选一，复制即用）

1. `搬家急出 闲置便宜处理 可小刀`
2. `闲置转让 用不上了 低价出 包邮`
3. `清仓闲置 低价甩 学生党友好`

### 文案（复制即用）

```
搬家整理，出几件闲置，都还能用，价格实在。
【东西】看你挂什么就写什么，比如「旧书 3 本」「耳机 1 副」「加湿器 1 台」
【成色】X 成新，正常使用痕迹
【价格】标实价，别虚高
【说明】同城可自提，外地包邮，不退不换
喜欢直接拍，私聊发细节图。
```

### 定价

- 标**实价**，参考闲鱼同款最低价的 8 折。
- 第一次不要纠结利润，¥9.9～¥29.9 之间，能快速出掉即可。

### 图片（拍 3 张就够）

| 张数 | 拍什么 |
|------|--------|
| 1 | 物品正面，白墙/纯色背景，光线亮 |
| 2 | 侧面/细节，能看清成色 |
| 3 | 包装或配件（有就拍，没有跳过） |

> 不用修图，手机原相机，光线好即可。**不要为拍照纠结超过 5 分钟。**

---

## 方案 B：数字产品（Tavily API Key，如果你不想碰闲置）

### 标题（复制即用）

`Tavily AI 搜索 API Key 月卡 现开现用`

### 文案（复制即用）

```
Tavily 官方 API Key，AI 搜索/Agent 开发用。
【内容】一个可用的 API Key，1000 credits/月
【交付】付款后发 Key + 使用说明
【注意】虚拟商品，售出不退，介意勿拍
```

### 定价

¥5～10。目标不是利润，是**成交一单、拿到第一个付款**。

### ⚠️ 风险提示

- 虚拟商品在闲鱼有下架/封号风险，发布前先搜「同类商品」看别人怎么挂、活不活得下来。
- 这是「拿第一笔钱」的路径之一，不是长期生意。如果 3 天内没曝光，换方案 A。

## 老板上架三步（今晚 15 分钟）

1. **打开闲鱼 App** → 点底部「+」→「发布闲置」
2. **复制标题 + 文案**，拍 3 张图（方案 A）或填 Key 信息（方案 B）
3. **点「发布」** → 截图发群里
