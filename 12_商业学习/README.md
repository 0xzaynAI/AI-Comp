# 商业学习 — 从摆摊到上市

> 生意不分大小，逻辑完全一样。从地摊开始学，把每一个概念吃透。

---

## 课程哲学

1. **从小到大**: 摆摊 → 小店 → 连锁 → 品牌 → 资本
2. **实在不飘**: 每节课必须会算钱、会算账、能落地
3. **案例优先**: 一个真实案例胜过十页理论
4. **学了就用**: 每模块附练习，用你自己的项目验证

## 学习建议

- **顺序学**：模块之间有依赖关系，不要跳
- **动手算**：每个模块的练习题请认真做，拿纸笔算
- **出门看**：逛街时用学到的框架分析你看到的每一个店铺/摊位
- **做了再说**：最好的学习方法是在楼下摆个摊

---

> Steve 注：这套课程的设计思路来自 Jobs 的第一性原理 — 把生意拆到最小原子单位「摆摊」，然后一层层往上搭。和 Musk 的「白痴指数」殊途同归：如果你不理解一个东西的最底层，你一定不理解它的上层。
