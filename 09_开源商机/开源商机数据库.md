> 负责人: L (筛选) + Steve (分析)

## 数据库说明

这是幻影旅团的开源商机监控数据库。每周自动从三个数据源抓取高增长项目，经过过滤和分析后入库。

### 过滤规则

| 排除 | 保留 |
|------|------|
| 编程语言/框架 | AI+垂直场景 |
| 论文复现 | SaaS 替代品 |
| 纯 CLI 工具 | 非开发者工具 |
| 面向开发者的 infra | 数据/可视化 |
| 开发者工具 | 内容创作 |
| | 生产力工具 |
| | 消费者工具 |

### 分类体系

- 🟢 `ai_app` — AI 应用层
- 🟢 `vertical_ai` — AI+垂直场景
- 🟢 `saas_alt` — SaaS 替代品
- 🟢 `tool_nondev` — 非开发者工具
- 🟢 `data_viz` — 数据/可视化
- 🟢 `content_creation` — 内容创作
- 🟢 `productivity` — 生产力工具
- 🟢 `consumer` — 消费者工具
- 🟢 `fintech` — 金融科技
- 🟢 `health` — 健康/医疗
- 🟢 `education` — 教育/学习
- 🔴 `infra_oss` — 基础设施（排除）
- 🔴 `dev_tool` — 开发者工具（排除）
- 🔴 `cli_tool` — CLI 工具（排除）
- 🔴 `lang_framework` — 编程语言（排除）
- 🔴 `paper_impl` — 论文复现（排除）

## 分析模板

对每个候选项目，回答以下问题：

1. **❓ 它解决了什么人的什么问题？**
2. **💰 用户愿意为这个问题的解决付多少钱？**
3. **🚀 能否用 1 周 MVP 做出一个更简单的收费版？**
4. **🏢 已有竞品是谁，他们怎么收费的？**
