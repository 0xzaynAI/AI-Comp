## 🥇 No.1 — TauricResearch/TradingAgents [[项目库/TradingAgents|📋项目详情]]

| 维度 | 详情 |
|------|------|
| 来源 | 🐙 GitHub Trending |
| Stars | ⭐ 59.8K（周增 +11,500 ⚡爆增） |
| 分类 | 金融科技 / AI Agent |
| 链接 | https://github.com/TauricResearch/TradingAgents |

**❓ 解决了什么问题？**
个人投资者缺乏机构级的量化交易分析能力。TradingAgents 用多 Agent LLM 框架自动做市场分析、策略生成、风险评估。

**💰 用户愿意付多少钱？**
**$20-50/月**。交易工具的付费意愿是所有消费品类里最高的之一。对标：TradingView Pro $15-30/月，TrendSpider $40-100/月。AI 加持的交易信号/分析有溢价空间。

**🚀 能否 1 周 MVP 做出更简单的收费版？**
✅ **可以**。核心路径：
- 不复制完整 TradingAgents，而是做「AI 交易信号简报」SaaS
- 接入免费的股票 API → 用 LLM 做技术面/基本面摘要 → 每日推送
- 1 周 MVP：Web 端 + 邮件推送，支持 5 只美股
- 收费点：更多股票、实时信号、回测功能

**🏢 已有竞品**
- TradingView（$15-30/月）— 图表+社区，AI 分析不是核心
- TrendSpider（$40-100/月）— 自动化技术分析
- LevelFields（$19-49/月）— AI 事件驱动交易
- **机会**：AI Agent 多维度分析 + 中文市场（A股/港股）是差异化切口

## 🥈 No.2 — Feather（Product Hunt） [[项目库/Feather|📋项目详情]]

| 维度 | 详情 |
|------|------|
| 来源 | 🦊 Product Hunt（May 2 日榜 #3，176 票） |
| 分类 | AI + 内容创作 |
| 链接 | https://www.producthunt.com/products/feather |

**❓ 解决了什么问题？**
普通人修图需要学 Photoshop，手机 App 又要上传隐私照片到云端。Feather = 本地运行的 AI 照片编辑器，隐私 + 简单。

**💰 用户愿意付多少钱？**
**$5-15/月**。对标：Adobe Lightroom $9.99/月、Luminar Neo $79 买断。本地 AI 修图是差异点（隐私敏感用户）。

**🚀 能否 1 周 MVP 做出更简单的收费版？**
✅ **可以**。核心路径：
- 用开源模型（如 Stable Diffusion inpainting + ControlNet）本地运行
- MVP 做 3 个功能：一键去背景、智能调色、人脸美化
- Electron 打包桌面 App → App Store 分发
- 免费 3 张/天，付费 $5/月无限用

**🏢 已有竞品**
- Adobe Lightroom（$9.99/月）— 云端 AI，不上传不能用
- Luminar Neo（$79 买断）— 本地运行但功能复杂
- Photoroom（$11.99/月）— 电商修图，需联网
- **机会**：完全本地 + 中文 UI + 比竞品便宜，切隐私敏感用户群

## 🥉 No.3 — Stanzio（Hacker News Show HN） [[项目库/Stanzio|📋项目详情]]

| 维度 | 详情 |
|------|------|
| 来源 | 🔶 Hacker News Show HN（92 票） |
| 分类 | AI + 内容创作 |
| 链接 | https://bestofshowhn.com/2026/5 |

**❓ 解决了什么问题？**
做 PPT 是每个职场人的痛点——排版、设计、结构化都要花大量时间。Stanzio 用 AI 把文本转成真正的 HTML 幻灯片。

**💰 用户愿意付多少钱？**
**$10-25/月**。对标：Gamma $8-20/月、Beautiful.ai $12-40/月、Canva Pro $13/月。AI 演示文稿工具是验证过的付费市场。

**🚀 能否 1 周 MVP 做出更简单的收费版？**
✅ **可以**。核心路径：
- 输入文字大纲 → LLM 生成结构化内容 → HTML/CSS 渲染为精美幻灯片
- MVP：支持 5 种模板，导出 PDF/PPTX
- 免费 3 个文稿，付费 $12/月无限
- 1 周出 MVP 完全可行（LLM API + 模板引擎）

**🏢 已有竞品**
- Gamma（$8-20/月）— AI 生成 PPT，200 万用户，已验证市场
- Beautiful.ai（$12-40/月）— 企业级
- Tome（$10-20/月）— AI 叙事
- **机会**：更轻量、更快、面向中文内容创作者。Gamma 不支持中文体验好
