## 四、Jobs/Musk 思维校准

### 4.1 Jobs 极简主义检验

**质问：如果本周只能做一件事，哪件？**

答案：把一份日报发到 100 个跨境卖家手里。而不是写 14 份调研报告、建 34 个项目库、出一个 391 行 PRD。

**暴露的问题**：我们的「产出文化」在自我强化 —— 写调研 → 写 PRD → 建系统 → 写更多调研。但 0 个用户接触到产品。

**Jobs 改法**：下周 MVP 必须上线。哪怕只有 TikTok 家居品类、手动出 3 期日报、飞书群发。砍掉所有「前置工作」，只问：用户今天能看到什么？

### 4.2 Musk 第一性原理检验

**质问：跨境情报雷达的物理约束是什么？**

- 不是「AI 能力不够」—— TikTok 视频 AI 解析不是瓶颈
- 不是「数据源太少」—— 公开数据足够起步
- **真正约束：用户触达**。没有渠道，再好的情报没人看。

第一性原理拆解：
```
最终目标：帮助跨境卖家卖更多货
├─ 前提 1：他们需要知道什么会火（信息）
├─ 前提 2：他们需要能获取这个信息（渠道）
└─ 前提 3：他们需要信任这个信息（验证）
```

当前 PRD 只覆盖了前提 1。前提 2 和 3 是真正的瓶颈。

**Musk 改法**：先不发产品，先建渠道。下周目标改：搞到一个 100 人跨境卖家群，手动出日报给他们。
