## 使用说明

### 1. 文件定位
这是团队**唯一**的任务管理文件，替代原来的 `任务进度.md`、`L_待办任务.md`、`Steve_待办任务.md`。

### 2. 任务ID 命名规则
- `B-xx` — 老板任务
- `L-xx` — L（Lawliet，首席分析师）任务
- `S-xx` — Steve（产品经理+CEO）任务
- 编号递增，不重复使用已完成的编号

### 3. 状态流转
```
⬜ 待办 → 🔵 进行中 → ✅ 已完成
                  ↘ 🔴 阻塞（需备注原因）
```

### 4. 创建任务
- **创建人**：谁分配任务填谁
- **处理人**：谁干活填谁
- **任务内容**：一句话说清要干什么
- **状态**：新建默认 `⬜ 待办`
- **创建日期**：分配当天日期
- 按处理人分组插入到对应区块（Boss / L / Steve）

### 5. 更新规则
| 谁 | 更新什么 |
|----|---------|
| **Steve** | 创建L/S任务、更新S任务状态、每日检查L进度后更新 |
| **L** | 完成任务后自行更新状态 → ✅ 已完成 + 完成日期 |
| **老板** | 更新B任务状态 |

### 6. 任务分配原则
- L 收到任务即开始执行，**不需要强调 DDL**
- 沟通过程中顺带一句「有空做下这个」即可
- 任务分配**走群聊**（幻影旅团），不走 DM

### 7. 排序规则
- 按状态排序：进行中 > 待办 > 已完成
- 同状态按创建日期倒序（新的在上）
