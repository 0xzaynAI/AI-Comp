# SocialKit + PostPeer (社媒抓取/发布 API 双产品)

> 来源: indiehackers | 分类: SaaS | 得分: 28/35
> URL: https://socialkit.dev

## 描述
Jonathan Geiger 的独立开发产品矩阵（第5、6款产品成功后辞职全职）。SocialKit：把 YouTube/TikTok/Instagram/Facebook/LinkedIn/X 的社媒内容转成干净数据（字幕、评论、数据、主页、AI 摘要）的统一抓取 API，上线13个月，$3.5K/月（$2.8K MRR + $700 一次性），110 个活跃订阅。PostPeer：统一调度/发布内容到所有主流平台的 API（LinkedIn/X/Instagram/TikTok/YouTube/Facebook），2026年4月上线，$2.9K/月，1K 用户。合计约 $6.4K MRR。打法亮点：无免费层（仅20 credits 即付费）、一次性 credit pack 占约20%收入（捕获厌恶订阅的开发者）、「竞争即验证」（对手 $20-80K/月证明市场存在）、复用 auth/账单/API key 基建让每款产品更便宜、靠 ChatGPT/Perplexity 推荐获客、WhatsApp 分钟级客服作护城河。曾把 CaptureKit（$127 MRR）以 $15K 卖掉（约10倍年收入）。验证「社媒数据/发布 API + 订阅制」方向，API 服务可抄性中高。
