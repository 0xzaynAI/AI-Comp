## 工作流约定

1. **分析先行** — 每个产品想法必须基于至少一份分析报告（01-04）
2. **先想后写** — 想法草案先放 05，足够成熟再进入 06
3. **一产品一目錄** — 进入 07 后，每个产品独立目录，含代码/设计/运营全部内容
4. **定期回测** — 已发布产品的数据回写 04_需求分析，形成闭环
5. **异步优先** — 副业时间有限，能用 AI 自动化的工作不手动做；沟通尽量异步（文档 > 即时消息）
