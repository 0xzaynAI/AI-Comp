**调研时间**：2026年7月

## 二、产业链结构

```
┌────────────────────────────────────────────────────────────────┐
│                      上游（零部件） — 利润最薄                  │
│  ┌───────────┐  ┌───────────┐  ┌───────────┐  ┌───────────┐  │
│  │ 电芯      │  │ PCB/芯片  │  │ 外壳结构件 │  │ 线材/其他  │  │
│  │ (成本~85%)│  │ (成本~10%)│  │ (成本~3%)  │  │ (成本~2%)  │  │
│  └─────┬─────┘  └─────┬─────┘  └─────┬─────┘  └─────┬─────┘  │
├────────┴───────────────┴──────────────┴──────────────┴─────────┤
│                      中游（制造） — 产能过剩、利润率极薄         │
│  ODM/OEM 代工厂: 深圳富士达、炬神电子、欣旺达、华美兴泰...      │
│  1000台起订即可贴牌，代工厂仅获个位数%利润                       │
├──────────────────────────────────────────────────────────────────┤
│                      下游（品牌+渠道） — 利润最厚                │
│  品牌: Anker/小米/罗马仕/华为/倍思/绿联/品胜/CUKTECH...          │
│  渠道: Amazon(53%电商占比)/京东/天猫/华强北/沃尔玛/线下零售      │
└──────────────────────────────────────────────────────────────────┘
```

**成本结构（10000mAh 为例）**：
- 电芯：~40-50元（85%）
- 电路板+芯片：~5-8元（10%）
- 外壳结构件：~2元（3%）
- 组装人工+包装：~2元（2%）
- **BOM总成本**：50-60元起

## 五、华强北在供应链中的角色

华强北不是单一市场，而是**珠三角电子产业链的"前店后厂"窗口**。

| 角色 | 详情 |
|------|------|
| 元器件集散中心 | 电芯、PCB、芯片、外壳一站式采购 |
| 公模方案输出地 | 多品牌共享3C认证外壳+电路方案，仅换外观/LOGO |
| 白牌OEM基地 | 1000台起订贴牌，三大件采购即组装 |
| 行业价格风向标 | "华强北堵车，全国手机配件价格波动" |
| 出海跳板 | 面向东南亚/非洲/中东的批发集散地 |

**价格数据（2025年7月实地走访）**：
- 1万mAh带3C认证批发价：**85-90元**（触底）
- 同规格无3C白牌：**~40元**（价差近一倍）
- 3C认证分摊成本：**15-20元/台**

**2025年后变化**：
- 深圳市场监管局下发通知：无3C认证充电宝严禁销售
- 20元以下白牌充电宝基本消失
- 价格中枢上移至 50-100 元
- 部分库存转销东南亚（3C要求宽松）

### 7.2 消费决策权重

1. **容量**（最核心）
2. **充电速度/快充协议兼容性**（权重快速上升）
3. **安全性/品牌信誉/3C认证**（2025年后极端重要）
4. **体积重量**（与容量 trade-off）
5. **价格**（下沉市场敏感，高端品牌溢价接受度提升）
6. **外观设计/IP联名**（年轻用户）
7. **附加功能**（自带线/支架/数显/磁吸 — 正从加分项变标配）

### 详细分析：Top 3 可切入方向

#### 🥇 MagSafe/Qi2 磁吸充电宝出海

- **为什么**：iPhone 12+全系支持 MagSafe，生态绑定深；Qi2 协议开放后安卓也可以
- **怎么做**：华强北公模外壳 + 力神/亿纬电芯 + 英集芯/IP5389方案 → 10000mAh磁吸充电宝
- **MVP成本**：BOM ~50-60元，加上认证 ~20元/台，起订量 1000台
- **定价**：亚马逊 $19.99-29.99（安克 MagGo 卖 $89.99，价差空间极大）
- **收入估算**：1000台 × ¥60利 = ¥6万净利（保守）
- **核心优势**：华强北触手可及，公模方案成熟，认证已有共享方案

#### 🥈 华强北公模贴牌

- **为什么**：3C认证新规后，白牌出清（20元以下的消失），合规产品需求暴增
- **怎么做**：选用共享3C认证的公模方案，仅改外壳/LOGO/Branding
- **MVP成本**：10000mAh 公模成品 ~50元/台，起订 1000台
- **定价**：50-80元（拼多多/淘宝/闲鱼），或 $15-20（Shopee/速卖通）
- **收入估算**：月销1000台 × ¥15利 = ¥1.5万/月
- **核心优势**：零研发，极快启动，1周可出货

#### 🥉 电商白牌→亚马逊跨境

- **为什么**：华强北50元拿货→亚马逊$25（180元），即使扣掉FBA/广告仍有利润
- **怎么做**：选1-2款通过FCC/CE/UN38.3认证的公模产品，FBA发货
- **核心优势**：深圳地理优势，信息差 + 供应链，已有苏珊等成功案例
- **关键**: 竞争激烈，需要差异化 Branding

## 📝 L 的笔记

1. **这是一个信息极度透明的行业**——供应商名单、BOM成本、品牌代工关系网上全有。信息差很小，但有两个差异点别人不掌握：
   - 一是**华强北触手可及**（多数跨境电商团队在杭州/广州，离供应链比我们远）
   - 二是**3C认证后公模方案共享**（多品牌共用一套3C外壳+PCB，这是合规贴牌的捷径）

2. **最有意思的信号**：罗马仕倒下后空出~100-200万台市场，但这不是我们吃的肉——那是华为/倍思/品胜的。我们要吃的是「3C认证后合规白牌替代」这个结构机会。

3. **不建议自己做品牌**——行业毛利率40%但净利率不到10%（参见Anker），品牌投入太大。更适合做**供应链套利**：华强北→公模贴牌→跨境电商/拼多多。

4. **如果要做产品，MagSafe磁吸赛道最值得试**：$87亿市场、iPhone绑定、安克卖$89.99我们卖$19.99、公模方案现成、1周出样品、利润空间30%+。

5. **华强北优势兑现路径**：
   - 第一步：去华强北走一圈，确认公模方案的3C认证共享模式细节
   - 第二步：拿1-2款公模成品，拍照上架亚马逊/拼多多测试
   - 第三步：跑通后再做差异化设计（外观/Branding/包装）
