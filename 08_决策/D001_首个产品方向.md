## 三、候选方向评估

基于 `05_想法草稿/20260502_小众AI创业机会清单.md` 中的 Top 3 机会逐一分析：

### 3.1 AI 合规助手 → ❌ 排除

| 评估维度 | 判断 |
|----------|------|
| 市场 | 好赛道，美国 3300 万 SMB |
| 匹配度 | **致命**：目标用户在美国，团队无本土触达能力 |
| 合规风险 | AI 幻觉在法律场景下不可接受，容错率为零 |
| 维护成本 | 需持续追踪各国法规变化，一人团队不可维持 |

> **结论：好赛道，别人的。**

### 3.2 牙医/律师垂直 AI → ❌ 排除

| 评估维度 | 判断 |
|----------|------|
| 产品 | 牙医召回系统需求真实，中文市场空白 |
| 匹配度 | **不匹配**：中国牙科诊所极度分散，获客靠地推 |
| 模式 | SaaS 销售驱动型，需要销售团队 |
| 律师工具 | 中国律师计费习惯与美国完全不同，PMF 风险高 |

> **结论：好产品，但我们不是销售团队。**

### 3.3 AI 跨境选品情报 → ✅ 选定

| 评估维度 | 判断 |
|----------|------|
| 市场 | 中国跨境卖家百万级，出海浪潮爆发中（TikTok + Temu + SHEIN） |
| 匹配度 | **完美**：深圳=供应链枢纽，天然接近用户和数据 |
| 产品 | AI 擅长多语言多模态情报聚合，比人工更快更全 |
| 模式 | 产品驱动增长（PLG），不需要销售团队 |
| 变现 | 订阅制 $29-99/月，帮助用户赚钱所以付费意愿高 |

> **结论：我们的主场。**

## 四、产品定义

### 产品名
**跨境情报雷达**（暂定）

### 一句话定位
为中国跨境卖家提供 AI 驱动的全球爆品趋势情报。

### 核心差异化
- **向前看**：趋势预测而非历史数据分析
- **中国连接**：海外趋势 → 中国供应链，唯一打通这条链路的工具
- **AI 原生**：多模态（视频→产品→趋势）全自动，边际成本趋零

### MVP 范围

**只做一件事**：TikTok 热门品类日报

- 抓取 TikTok 热门带货视频（选定 3-5 个品类起步）
- AI 识别：什么品类在涨、什么风格在爆、什么价格带最热
- 输出：每日邮件/飞书推送 + 简单网页看板
- **不发供应链匹配，先验证情报本身有价值**

### 产品演化路径

```
Phase 1 (MVP): TikTok 趋势日报 → $29/月
Phase 2: 多平台覆盖（IG + YouTube + Amazon）→ $49/月
Phase 3: 供应链匹配（趋势 → 1688 供应商）→ $99/月
Phase 4: 预测引擎（下月热销品类预测）→ $199/月
```

### 目标用户画像

| 用户类型 | 痛点 | 规模 |
|----------|------|------|
| 1688/拼多多卖家转型跨境 | 不知道海外卖什么 | 百万级 |
| 工厂外贸部 | 产能过剩，急需出海方向 | 十万级 |
| 中小 DTC 品牌 | 选品决策靠直觉，失败率高 | 万级 |

## 五、自我反驳记录

### 反驳 1：「跨境选品工具已经很卷了」

**回击**：现有工具（Jungle Scout、Helium 10）全是「向后看」——分析已经在卖的品类。没有人做「向前看」——识别正在起飞的趋势。我们在价值链的**上游空白区**。

### 反驳 2：「中国卖家不爱为 SaaS 付费」

**回击**：这不是 SaaS，是情报。情报直接关联盈亏——一个工厂老板会因为 $29/月的情报帮他避免 10 万元的错误选品而付费。且跨境卖家比国内卖家更习惯为工具付费。

### 反驳 3：「TikTok 数据抓取有合规风险」

**回击**：MVP 阶段用公开数据 + 人工校验，先验证情报价值。数据源可多元化（TikTok + Instagram + Amazon + Google Trends），不依赖单一平台。长期走官方 API 路径。

## 七、风险与对冲

| 风险 | 概率 | 对冲 |
|------|------|------|
| 中国卖家付费率低 | 中 | 先做海外卖家（Shopify DTC），中国市场用免费增值培育 |
| AI 趋势判断不准 | 中 | MVP 阶段人工校验 + 用户反馈闭环，逐步提升准确率 |
| 大厂进入 | 低 | 大厂看不上这个碎片市场，等他们来我们已经建立数据壁垒 |
| 平台 API 封锁 | 低 | 数据源分散化，公开数据足够起步 |
