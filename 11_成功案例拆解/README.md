# 11_成功案例拆解

> **核心理念**: 找到行业里已经成功的人，研究他们做了什么产品、怎么做的，看能否复制。
> 模仿是成功最快的方式。

## 📂 目录结构

```
11_成功案例拆解/
├── README.md              ← 本文件
├── 人物库/                 ← 成功者个人档案（一人一文件）
│   └── 模板_人物.md
├── 产品库/                 ← 他们的产品拆解（一产品一文件）
│   └── 模板_产品.md
└── 访谈记录/               ← 播客/视频/文章访谈原文或摘要
```

## 🔍 人物筛选标准

- **类型**: Indie Hacker / Solopreneur / 小团队（<10人）创始人
- **验证**: 有实际收入数据（MRR/ARR），非纯内容创作者
- **可复制性**: 产品形态适合一人公司或小团队复制
- **相关性**: 产品方向与我们的能力圈有交集

## 📋 调研维度（给 L 的任务模板）

对每个人物，L 需要调研：

1. **基本信息**: 名字、背景、所在地、团队规模
2. **产品线**: 做过哪些产品，每个产品的 MRR/ARR
3. **增长路径**: 如何获客？渠道是什么？
4. **技术栈**: 用了什么技术？
5. **商业模式**: 定价策略、付费转化路径
6. **关键访谈**: 找到他们的播客/文章/推文，提取核心洞察
7. **可复制性评估**: 我们能否做类似产品？差距在哪？

## 📊 优先级

| 优先级 | 人物类型 | 示例 |
|--------|----------|------|
