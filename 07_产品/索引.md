## 产品目录结构

每个产品目录标准格式：

```
07_产品/[产品名称]/
├── README.md          ← 产品主页（定位、状态、关键指标）
├── PRD.md             ← 产品需求文档（从 06 迁移或链接）
├── 设计/              ← UI/UX 设计稿、原型
├── 开发/              ← 代码仓库链接或技术文档
├── 运营/              ← 用户反馈、运营数据、增长实验
├── 市场/              ← 竞品追踪、市场变化
└── 复盘/              ← 迭代复盘、经验教训
```
