# 📋 06_产品需求文档

> 将 05 中的想法草案转化为正式产品需求文档（PRD）。

---

## PRD 标准模板

每份 PRD 应包含：

```markdown
# [产品名称] · 产品需求文档 v1.0

## 1. 产品概述
- 一句话描述
- 目标用户
- 核心价值主张

## 2. 市场与竞品
- TAM / SAM / SOM
- 竞品矩阵（功能对比表）
- 差异化策略

## 3. 用户故事
- 主要使用场景（3-5个）
- User Journey Map

## 4. 功能需求
- P0（MVP 必做）
- P1（V1.1）
- P2（后续迭代）

## 5. 非功能需求
- 性能 / 安全 / 合规

## 6. 技术方案
- 技术栈选型
- 第三方依赖
- 架构概要

## 7. 商业模式
- 定价策略
- 收入预测（Year 1）

## 8. 里程碑
- Week 1-2: MVP 开发
- Week 3: 内测
- Week 4: 公开发布
```
