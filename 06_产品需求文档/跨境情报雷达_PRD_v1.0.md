## 一、产品概述

### 1.1 一句话定位

**为中国跨境卖家提供 AI 驱动的全球爆品趋势情报——告诉你"什么会火"，而不是"什么已经火了"。**

### 1.2 我们要解决的问题

| 问题 | 严重度 | 现有方案 | 我们的方案 |
|------|--------|---------|-----------|
| 选品靠"感觉"和"跟风"，失败率 ~90% | 🔴 致命 | 看竞品榜单（向后看） | AI 识别正在起飞的趋势（向前看） |
| TikTok / Amazon / Temu 数据割裂，跨平台分析全靠人工 | 🔴 严重 | 买 3 个工具手动对比 | 一站式跨平台情报 |
| 趋势发现太慢，别人卖爆了才知道 | 🟡 严重 | Kalodata/FastMoss 看昨天数据 | 提前 48-72 小时预警 |
| 海量视频/帖子信息过载，看不过来 | 🟡 高 | 人工刷 TikTok | AI 多模态解析+摘要 |
| 新手不知道从哪开始，工具太复杂 | 🟠 中 | 知识付费课程（$299-999） | AI 引导式选品，0 学习成本 |

### 1.3 核心差异化

```
传统工具：    历史数据 → 手工分析 → 跟风决策  （向后看，比谁手快）
跨境情报雷达： 实时信号 → AI 解析 → 预判决策  （向前看，比谁看得准）
```

| 维度 | 现有工具 | 跨境情报雷达 |
|------|---------|------------|
| **时间轴** | 过去（已发生的销量/排名） | 现在→未来（正在起飞的趋势） |
| **数据源** | 单平台（Amazon 或 TikTok） | 跨平台聚合（TikTok+Amazon+Temu+IG） |
| **输出** | 数据表格（需人工解读） | AI 情报简报（结论+行动建议） |
| **用户门槛** | 高（需懂工具和跨境电商） | 低（自然语言交互） |
| **AI 角色** | 辅助功能（AI 写作/AI 标签） | 核心引擎（AI 发现→分析→推荐） |

### 2.1 市场体量

| 层级 | 数据 | 置信度 |
|------|------|--------|
| **TAM** — 全球电商 SaaS | $200B (2024) → $700B (2034)，CAGR 12.5% | ⭐⭐⭐ |
| **SAM** — 中国跨境卖家工具支出 | $24-60B / 年 | 估算 ±50% |
| **SOM** — AI 选品情报细分 | 当前 $360M-3.6B，2028 $2-10B | 估算 ±50% |
| **中国出海活跃卖家** | 200-300 万（跨平台去重） | 估算 |
| **TikTok Shop 美国 2025** | $150B+ GMV，231K 店铺，+5000% from 2023 | ⭐⭐⭐⭐ |

### 2.2 竞品格局关键结论

| 发现 | 含义 |
|------|------|
| **Amazon 选品双寡头**（JS + H10），数据准确但"向后看" | 不在正面战场竞争 |
| **TikTok 选品全是中国团队**（Kalodata/FastMoss/Shoplus/EchoTik） | 中国团队有天然优势 |
| **无人做跨平台统一选品**（Amazon+TikTok+Temu） | 🔥 我们的最大空白 |
| **所有工具都是"数据分析工具"，不是"AI 情报工具"** | 差异化核心 |
| **$19-49/月的 AI 情报推送是无人区** | 🔥 价格空白带 |

### 2.3 我们从竞品中学到的

- ✅ Jungle Scout：简洁就是竞争力，数据准确度 > 功能数量
- ✅ Kalodata：TikTok 原生专注，15 分钟数据刷新是卖点
- ✅ 卖家精灵：170 万注册用户证明「中国卖家愿意为中文工具付费」
- ❌ Helium 10：功能堆砌≠好用，学习曲线太陡会劝退目标用户
- ❌ FastMoss：320 万用户声称≠真实付费，数据透明度低

| | 新手小明 | 腰部 Linda | 头部老王 |

| **月 GMV** | <$5K | $30-80K | $500K-2M |

| **选品失败率** | 90%+ | 50-70% | 20-30% |
| **单品试错成本** | ~$3,000 | ~$8,000 | ~$30,000 |
| **当前工具月费** | $0-29 | $200-400 | $2,000-5,000 |
| **愿为我们付费** | $19-29/月 | $79-149/月 | $299-999/月 |
| **决策周期** | 1-3 天 | 1-2 周 | 1-3 月 |
| **优先级** | 🥈 第二波获客 | 🥇 MVP 核心用户 | 🥉 长期升级路径 |

### 3.2 MVP 聚焦：腰部卖家（Linda）

**为什么是她？**
- 付费意愿明确（⭐⭐⭐⭐）、有持续性、有口碑传播力
- 痛点最锐利：跨平台数据割裂、AI 工具"还不够智能"
- 她的行为模式可标准化为产品功能
- 她是新手小明的"偶像"，头部老王的"情报源"

### 3.3 关键场景：Linda 的周一早晨

> Linda 在周一早会上发现一个竞品突然冲上小类 Top 20，7 天销量翻了 3 倍。她需要立刻决策：跟进还是放弃？如果要跟进，这个品在 TikTok 上有内容红利吗？1688 哪家供应商能 7 天内出样品？

**她需要的是**：一个一站式"情报驾驶舱"，能在 5 分钟内给出「竞品为什么爆 + TikTok 同类内容表现 + 供应链可行性 + 预测利润」。

## 四、产品方案

### 4.1 产品架构

```
┌─────────────────────────────────────────────────────┐
│                    用户界面层                          │
│  ┌──────────┐  ┌──────────┐  ┌──────────────────┐   │
│  │ 飞书 Bot  │  │ Web 看板  │  │ 邮件/微信推送     │   │
│  └──────────┘  └──────────┘  └──────────────────┘   │
├─────────────────────────────────────────────────────┤
│                    AI 情报引擎                         │
│  ┌──────────┐  ┌──────────┐  ┌──────────────────┐   │
│  │ 趋势发现  │  │ 竞品解析  │  │ 机会评分 & 简报   │   │
│  │ 多模态抓取 │  │ 利润测算  │  │ 自然语言生成      │   │
│  └──────────┘  └──────────┘  └──────────────────┘   │
├─────────────────────────────────────────────────────┤
│                    数据采集层                          │
│  ┌────┐ ┌────┐ ┌────┐ ┌────┐ ┌────┐ ┌──────────┐  │
│  │TikTok│ │Amazon│ │Temu│ │IG │ │YT │ │公开数据源  │  │
│  └────┘ └────┘ └────┘ └────┘ └────┘ └──────────┘  │
└─────────────────────────────────────────────────────┘
```

### 4.2 核心功能模块

#### 模块 A：趋势发现引擎（Trend Discovery）
- **输入**：TikTok/Amazon/Temu/IG 公开内容流
- **处理**：AI 多模态分析（视频→产品识别→趋势聚类）
- **输出**：正在崛起的品类/风格/价格带信号

#### 模块 B：竞品情报解析（Competitive Intel）
- **输入**：用户关注的竞品/品类
- **处理**：AI 评论挖掘 + 定价/利润分析
- **输出**：竞品弱点、差异化机会、利润估算

#### 模块 C：每日情报简报（Daily Brief）
- **格式**：邮件/飞书/Web，每天早上 8:00（卖家上班前）
- **内容**：
  - 🔥 24h 趋势信号（3-5 条，带置信度）
  - 📊 重点关注品类动态
  - ⚠️ 竞品异常预警
  - 💡 本周值得关注的蓝海机会

#### 模块 D：机会打分卡（Opportunity Score）
- **维度**：需求增速 × 竞争密度 × 利润空间 × 供应链可行性 × 趋势持续度
- **输出**：0-100 综合分 + 各维度拆解

### 4.3 核心交互：自然语言查询

> 用户：「最近一周美国 TikTok 上有什么家居品类在涨？」
>
> Radar：「检测到 3 个信号：① 硅胶冰格模具（7天增速 +340%，竞品 <50 个），② 磁吸厨房计时器（视频互动率 8.2%），③ 可折叠沥水篮（Amazon 同步上涨，搜索量 +120%）。推荐优先关注 #1，竞争低、利润空间 60%+、1688 供货充足。详细分析？」

## 五、MVP 范围

### 5.1 MVP 核心原则

> **只做一件事，做到极致：TikTok 跨品类趋势日报。**

不做：供应链匹配、多平台、预测引擎、API、团队协作、自定义看板。

### 5.2 MVP 功能清单

| 功能 | 优先级 | 说明 |
|------|--------|------|
| TikTok 热门带货内容抓取 | P0 | 覆盖美区，聚焦 5 个品类（家居/美妆/电子/服饰/运动） |
| AI 趋势识别与聚类 | P0 | 从视频内容中识别「品类+风格+价格带」三维信号 |
| 每日情报邮件推送 | P0 | 每天早上 8:00 HKT 发送，Markdown 格式 |
| 简单 Web 看板 | P0 | 展示近 7 天趋势信号列表+搜索 |
| 用户订阅管理 | P1 | 邮箱注册、付费开通、取消 |
| 飞书 Bot 推送 | P1 | 老板 + 种子用户用飞书，先不做公开 |
| 趋势详情页 | P1 | 点击信号 → 详情（数据曲线+AI 分析摘要） |
| 自然语言查询 | P2 | MVP 后第 1 个迭代 |

### 5.3 MVP 明确不做

| 不做 | 原因 | 何时做 |
|------|------|--------|
| Amazon/Temu 数据 | 先验证 TikTok 情报价值 | Phase 2 |
| 供应链匹配（1688 对接） | 复杂度高，先验证情报需求 | Phase 3 |
| AI 预测引擎 | 需要数据积累 | Phase 4 |
| 多语言（英文版） | MVP 只做中文 | Phase 2 |
| 达人/KOL 数据 | 非核心路径 | 待验证 |

## 六、技术架构

### 6.1 技术选型

| 层 | 技术 | 理由 |
|----|------|------|
| **数据采集** | Python (Playwright/httpx) + Cron 定时任务 | 轻量，公开数据爬取 |
| **AI 引擎** | DeepSeek V4 / GPT-4o 多模态 | 视频→文本→结构化分析 |
| **后端** | Python FastAPI | 快速开发，AI 生态好 |
| **数据库** | PostgreSQL + Redis | 时序数据+缓存 |
| **前端** | Nuxt.js / Next.js (轻量 SPA) | 现代、快速、SEO 友好 |
| **部署** | VPS (阿里云/腾讯云香港) | 深圳团队，低延迟，成本可控 |
| **推送** | Resend (邮件) + 飞书 Webhook | 低代码集成 |

### 6.2 数据流

```
定时抓取 (每小时)
  TikTok 公开 API / 页面解析
    → 原始内容（视频标题、标签、互动数据）
      → AI 多模态分析（视频帧→品类/风格识别）
        → 趋势聚类（时间窗口 24h/7d/30d）
          → 异常检测（偏离基线 2σ 触发预警）
            → 简报生成（LLM 摘要 + 建议）
              → 用户推送（邮件/飞书/Web）
```

### 6.3 AI 引擎设计

**Prompt 链架构**：

```
Step 1: 视频分类
  输入: 视频标题 + 标签 + 封面图
  输出: {品类, 子品类, 风格标签[], 价格带}

Step 2: 趋势检测
  输入: 过去 N 天的同品类内容聚合 + 互动数据
  输出: {趋势方向(↑/↓/→), 增速%, 置信度, 信号强度}

Step 3: 简报生成
  输入: Top 10 趋势信号 + 上下文
  输出: Markdown 简报（每个信号: 一句话总结 + 数据 + 行动建议）
```

## 七、商业模式

### 7.1 定价策略

| 层级 | 价格 | 目标用户 | 核心功能 | 预期占比 |
|------|------|---------|---------|---------|
| **免费** | $0 | 新手试水 | 每日 1 条趋势 + 3 天回溯 | 70% 用户，0% 收入 |
| **Pro** | **$29/月** ($199/年) | 腰部卖家 | 完整日报 + 趋势详情 + 7 天回溯 | 20% 用户，60% 收入 |
| **Team** | **$99/月** ($799/年) | 小团队 | Pro + 竞品监控(5个) + 自然语言查询 + 30 天回溯 | 8% 用户，30% 收入 |
| **Enterprise** | **$299/月** | 大卖/品牌 | API 接入 + 定制品类 + 专属简报 | 2% 用户，10% 收入 |

**定价逻辑**：
- $29 是 L 调研确认的"甜点区间"底部，低于 H10 入门版 ($49)、Kalodata Pro ($46)
- 年付 7 折锁定留存，降低流失
- 对标"替代成本"：一个失败选品 = $3,000-8,000 → $29/月 是 0.1-0.4%

### 7.2 收入模型（保守估计）

| 时间 | 免费用户 | 付费用户 | 转化率 | MRR | ARR |

| M3 | 500 | 35 | 7% | $1,015 | — |
| M6 | 1,500 | 120 | 8% | $3,480 | — |
| M12 | 5,000 | 500 | 10% | $14,500 | $174K |

### 7.3 用户获取

| 渠道 | 方式 | 成本 | 预期效果 |
|------|------|------|---------|
| **内容营销** | 公众号/知乎/雨果网 趋势周报 | 时间 | 主要获客渠道 |
| **社群裂变** | 卖家群分享"今日趋势"截图 → 引导注册 | $0 | 病毒传播 |
