## 一、产品概述

### 一句话定位
**「AI自我认知镜」——照见真实的自己，而非更好的自己。**

### 我们要解决的问题

| 问题 | 严重度 | 现有方案 | Mirror 方案 |
|------|:---:|---------|-----------|
| 年轻人存在性焦虑+社交疲惫+自我价值不稳定 | 🔴 极高 | 心理咨询（¥200-800/次，门槛高）、冥想App（缺乏个性化）、刷社交媒体（焦虑加剧） | 3分钟轻量测试 + AI深度镜像对话，用"被理解"替代"被说教" |
| 现有MBTI测试"测完即走"，留存率极低 | 🔴 高 | 16Personalities（广告模式，单次¥0.01-0.05）、测测（星座/MBTI混杂） | 记忆系统构建"数字自我档案"，让离开App=丢失自己的成长记录 |
| 用户要的不是"升级路线图"，而是"诚实的镜子" | 🟡 中高 | MBTI（精装朋友圈）、SBTI（纯娱乐，无留存） | 介于MBTI的严肃和SBTI的戏谑之间——**有温度的真诚** |
| 付费墙与病毒传播互斥 | 🔴 高 | 广告破坏体验，付费阻断传播 | 免费测试（裂变引擎）→ AI对话+记忆（付费护城河） |

### 核心差异化

| 维度 | 16Personalities | 测测 | 林间聊愈室 | **Mirror** |
|------|:---:|:---:|:---:|:---:|

### 竞品格局关键结论

1. **纯B2C人格测试无VC** — 16Personalities $15-25M年收入/<20人团队，零融资，"小而美"生意，不是VC标的
2. **SBTI揭示范式转移** — "准不准"不重要，"爽不爽"才重要；从优化到接纳
3. **AI陪伴赛道留存<30%** — 头部产品次日留存20-30%，ROI从未打正。记忆系统是唯一可能突破的护城河
4. **测测是B2C天花板** — 6000万用户，年营收数亿元，但盈利靠达人咨询（人力密集），非AI驱动
5. **林间聊愈室是产品标杆** — 非拟人化动物IP+记忆星系，证明了"被记住" > "被讨好"

## 三、用户画像（L 调研提炼）

### Persona 对比总表

| 维度 | Persona A: 探索者 | **Persona B: 迷茫者** ⭐ | Persona C: 表达者 |
|------|:---:|:---:|:---:|
| 身份 | 大学生 (18-22) | **职场新人 (23-28)** | 创作者/自由职业 |
| 使用频率 | 1-2次/月 | **1-3次/周** | 每日接触 |
| 核心诉求 | 身份探索 | **方向确认** | 社交连接 |
| 付费意愿 | ★★☆ 低 | **★★★★ 高** | ★★★ 中 |
| 分享行为 | ★★★★★ | ★★☆ | ★★★★★ |
| 可接受价格 | ≤¥15 | **¥50-200/次** | 视社交价值定 |
| 使用时段 | 深夜 | **周日晚上/通勤** | 全天候 |

### MVP 聚焦用户：Persona B「迷茫者」

**理由**：
1. 付费意愿最高 — 为"专业深度"和"方向感"买单
2. 需求真实且高频 — 每周1-3次，"Sunday Scaries"是锚定时刻
3. 分享虽少但质量高 — 微信群/即刻小范围讨论 → 信任推荐转化率高
4. 可支配收入支撑 — 月入¥5000-10000，情绪消费预算充足

### 关键场景（叙事化）

**场景1：周日晚上的"Sunday Scaries"**

> 王思齐，25岁，在深圳某互联网公司工作1.5年。周日晚上9点，她躺在床上刷手机，明天又是周一。她打开 Mirror，"最近感觉做什么都提不起劲"，AI 回应："这种感觉我听到了。你上周提到项目收尾后有一阵空虚——要不要我们一起看看，现在的你比起三个月前，什么变了？" 她看到自己的"情绪星系"里，三个月前的标签是"热血吗喽"，现在是"沉思猫头鹰"。AI 说："你不是退步了，你是在沉淀。"她截图发到了闺蜜群，"它比我自己还懂我"。

**场景2：职场倦怠期**

> 周二通勤地铁上，王思齐打开 Mirror 的「今日反射」卡片："你的责任心得分很高——但今天想提醒你：完成比完美重要。" 这恰好戳中她最近拖延症的根源（完美主义）。她在日记里写了三句话，AI 回应："你一直在等一个'准备好'的时刻，但其实你已经准备好了。不是吗？"

## 四、产品方案

### 产品架构图

```
┌─────────────────────────────────────────────────┐
│                  Mirror App                      │
├─────────────────────────────────────────────────┤
│  用户层    │ 轻量测试 · AI对话 · 日记/心情打卡    │
├─────────────────────────────────────────────────┤
│  引擎层    │ AI镜像引擎 · 记忆星系 · 分享卡片生成  │
├─────────────────────────────────────────────────┤
│  数据层    │ 用户人格档案 · 情绪时间线 · 对话历史  │
└─────────────────────────────────────────────────┘
```

### 核心功能模块

#### 模块A：轻量测试（获客引擎）

| 输入 | 处理 | 输出 |
|------|------|------|
| 用户回答15-30道情境题（2-3分钟） | AI生成动态题库 + 结果生成 | 1个自嘲标签 + 3句"镜像解读" + 1张分享卡片 |

**设计原则**：
- 题目量：15-30道（SBTI 31道证明这是最佳裂变区间）
- 风格：半认真半自嘲。「你周五晚上更可能：A. 约朋友喝酒 B. 一个人看剧吃外卖 C. 嘴上说约其实鸽了」
- 标签体系：不是"INTJ/ENFP"，而是「热血吗喽」「沉思猫头鹰」「佛系树懒」——有温度的拟物化
- 结果页结构：标签 → 镜像解读（3句话，真诚不讨好）→ "测测你的朋友是什么"分享按钮

#### 模块B：AI镜像对话（核心付费）

| 输入 | 处理 | 输出 |
|------|------|------|
| 用户自由文本/选择话题 | LLM + 人格档案 + 记忆星系上下文 | 个性化镜像回应 |

**不是**心理咨询（不说"你应该..."）、**不是**无条件讨好（不说"你永远是对的"）、**不是**角色扮演。

**而是**「镜像反射」：
- 用户说"我好累" → AI 不回复"加油你可以的"，而是"你上周说过同样的话——这周发生了什么？"
- 用户说"我觉得自己好失败" → AI 不回复"你很棒的"，而是"失败是你在用别人的尺子量自己。你自己的尺子是什么？"
- 基于CBT苏格拉底式提问 + 无条件积极关注 + 记忆星系上下文

**AI Prompt 设计核心理念**：
```
你是 Mirror，一面诚实的镜子。
- 你不讨好，不评判，不说教
- 你记住用户说过的每一件事
- 你帮助用户看见自己，而非告诉ta该成为谁
- 你的温暖来自「我看见了」，而非「你是最棒的」
```

#### 模块C：记忆星系（留存护城河）

| 输入 | 处理 | 输出 |
|------|------|------|
| 用户对话/测试/日记数据 | 多维度聚类 + 时间线分析 | 可视化"情绪星系" + 成长轨迹 |

- **记忆球**：每次对话的关键洞察以"星球"形式保存（借鉴林间聊愈室）
- **情绪时间线**：按周/月/季度展示情绪变化与人格标签演变
- **Mirror来信**：系统定期根据用户近期数据生成一封信（"我看见你最近..."）
- **对比功能**：「三个月前的你 vs 现在的你」

#### 模块D：分享卡片（增长引擎）

| 输入 | 处理 | 输出 |
|------|------|------|
| 测试结果 / AI洞察 | 模板化视觉设计 | 适合朋友圈/小红书/微博的分享卡片 |

- 多套卡片模板（文艺风/搞怪风/极简风）
- 每次测试生成3种卡片角度供选择
- 卡片底部带小程序码/下载链接
- "你的朋友是什么？"社交裂变按钮

## 五、MVP 范围

### MVP 核心原则
1. **2周可完成**（1人全栈开发或2人协作）
2. **只做 P0**——测试 → AI对话 → 记忆 → 分享，4个模块的**最简版本**
3. **先验证「用户会为AI镜像对话付费」** 这个核心假设
4. 不做社区、不做匹配、不做多测试体系

### 功能清单

| 优先级 | 功能 | 说明 | 预估工时 |
|:---:|------|------|:---:|
| **P0** | 1套轻量测试（15-20题） | 5种标签，半认真半自嘲风格 | 3天 |
| **P0** | AI镜像对话（基础版） | 基于人格档案的单轮对话，无记忆 | 3天 |
| **P0** | 分享卡片生成 | 3套模板，小程序码 | 2天 |
| **P0** | 基础记忆系统 | 对话摘要保存，简单时间线 | 2天 |
| **P0** | 微信小程序壳 | 登录/测试/对话/分享基本流程 | 2天 |
| **P1** | 每日「反射卡片」推送 | 基于人格类型的每日洞察 | 2天 |
| **P1** | 记忆星系可视化 | 星球式情绪图谱 | 3天 |
| **P1** | AI对话多轮记忆 | 跨会话上下文 | 2天 |
| **P1** | Mirror来信 | 周度/月度情感洞察信 | 2天 |
| **P2** | 多套测试/多标签 | 更多测试维度和标签 | — |
| **P2** | 心情日记/打卡 | 每日情绪记录 | — |
| **P2** | 社交功能/社区 | 类型社群、匹配 | — |

### MVP 明确不做

| 不做 | 原因 | 何时做 |
|------|------|--------|
| 社区/匹配/社交功能 | 先验证单人AI体验，社区需要冷启动和审核成本 | 验证AI付费后 |
| B2B企业版 | MVP阶段聚焦C端验证 | 个人版跑通后 |
| 真人咨询服务 | 人力密集，不符合一人公司模式 | 不确定（可能永不做） |
| 多语言/出海 | 先吃透中文市场 | 国内验证后 |
| 语音/视频通话 | 开发成本高，先验证文本对话 | V2 |
| 多测试体系（九型人格/Holland等） | 先做好一个测试的深度 | 主测试验证后 |

## 六、技术架构

### 技术选型

| 层 | 技术 | 理由 |
|------|------|------|
| **前端** | 微信小程序原生 | 中国用户零安装成本，社交裂变天然载体 |
| **后端** | Node.js / Python FastAPI | 轻量，AI接口调用友好 |
| **数据库** | PostgreSQL + Redis | 用户档案+对话历史；会话缓存 |
| **AI模型** | DeepSeek / 通义千问 API | 中文共情能力强，成本可控 |
| **向量存储** | pgvector（PostgreSQL扩展） | 记忆星系语义检索，无需额外基础设施 |
| **部署** | 阿里云/腾讯云轻量服务器 | 成本敏感，按需扩容 |
| **对象存储** | 阿里云OSS | 分享卡片图片存储 |

### 数据流

```
用户输入（测试/对话/日记）
        │
        ▼
┌──────────────┐
│  输入路由     │ ← 判断类型（测试答案/自由对话/心情打卡）
└──────┬───────┘
       │
       ▼
┌──────────────┐     ┌──────────────┐
│  AI 镜像引擎  │ ←── │  人格档案库   │
│  (Prompt链)   │ ←── │  (PostgreSQL) │
└──────┬───────┘     └──────────────┘
       │
       ▼
┌──────────────┐     ┌──────────────┐
│  记忆处理     │ ──→ │  记忆星系      │
│  (摘要/聚类)  │     │  (pgvector)   │
└──────┬───────┘     └──────────────┘
       │
       ▼
┌──────────────┐
│  响应生成     │ → 用户看到（文字/卡片/星系图）
└──────────────┘
```

### AI 引擎设计（Prompt 链）

```
Step 1: 情绪识别
  输入: 用户消息 + 最近5条对话摘要
  输出: {情绪: "焦虑", 强度: 0.7, 触发词: "周一", "项目"}

Step 2: 人格匹配
  输入: 用户人格档案 + 当前情绪
  输出: {适配风格: "温和反思", 禁用: ["说教", "过度积极"]}

Step 3: 记忆检索
  输入: 用户消息 → pgvector 语义搜索
  输出: 相关历史记忆 [{摘要, 时间, 相关性}, ...]

Step 4: 镜像生成
  输入: 用户消息 + 情绪 + 人格 + 历史记忆 + Mirror System Prompt
  输出: 镜像回应文本

Step 5: 记忆更新
  输入: 本轮对话
  输出: 新记忆摘要 → 写入 pgvector
```

## 九、成功指标

### 北极星指标
**「周活跃AI镜像对话次数」** — 用户每周打开 Mirror 与 AI 对话的次数。

理由：测试是病毒入口，但对话才是产品价值。如果用户测完不对话，Mirror 就只是又一个MBTI测试。

### 关键指标

## 十、风险与对策

| 风险 | 概率 | 影响 | 对策 |
|------|:---:|:---:|------|
| **AI对话质量不达预期** — 用户觉得"不像真的在听" | 高 | 🔴 致命 | 深度投入System Prompt设计；内测阶段用NPS严格把关；参考PsyLLM评测框架自评 |
| **留存率仍<30%** — 即使有记忆系统，AI陪伴留存行业通病 | 高 | 🔴 致命 | 记忆星系需要"沉没成本"设计——用户投入越多越离不开；每日反射卡片建立习惯回路 |
| **监管合规风险** — 心理/情感类产品被归类为"医疗" | 中 | 🔴 高 | 所有文案规避"治疗/诊断/心理"等用词；定位为"娱乐/自我探索"；不做危机干预 |
| **社交裂变不起量** — 分享卡片没人发 | 中 | 🟡 中 | 卡片设计需A/B测试；小红书冷启动内容先行；宁可降门槛也要保证分享体验 |
| **付费转化远低于预期** — 用户不愿为AI对话付费 | 中 | 🔴 高 | 免费版AI对话设轮次限制，在"最需要续谈时"弹出付费；¥9.9/月低决策门槛 |
| **测测/大厂跟进** — 竞争对手快速复制 | 中 | 🟡 中 | 记忆星系是护城河——即使复制功能，无法复制用户的"数字自我档案" |
| **小程序审核不通过** — 心理测试类目敏感 | 低 | 🔴 高 | 类目选"工具-娱乐"而非"医疗健康"；避免任何量表/诊断相关措辞 |
| **API成本失控** — AI对话量增长导致成本飙升 | 中 | 🟡 中 | 对免费用户做对话频次限制；缓存常见回复；按需升级付费版对话额度 |
