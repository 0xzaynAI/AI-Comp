## 一、产品概述

**AI 融资 Pitch Deck 生成器——中文创业者首选。**

### 我们要解决的问题

|------|--------|----------|-----------|
| 创业者做融资PPT耗时极长（平均40-80小时/份），PPT设计能力不足 | 🔴 极痛 | 手动PPT（低效）/ 通用AI PPT工具（缺乏融资逻辑） | AI 自动生成带融资逻辑的 Pitch Deck，内置商业模式画布+财务预测+竞品分析框架 |
| 中国创业者用 Gamma/Beautiful.ai 面临全英文界面、支付障碍、中文排版差 | 🟡 中等 | 接受糟糕体验或放弃使用 | 中文原生体验，微信/支付宝支付，中文排版精细化 |

| 投资人看大量BP，80%的PPT因「逻辑不清/排版差」在前30秒被pass | 🔴 极痛 | — | AI 从投资人视角反向优化：清晰度检查、逻辑链验证、视觉冲击力评估 |

| **MVP 可触达 SAM** | 中国活跃早期创业者/孵化器/加速器 = **约50-100万人** | ⭐⭐⭐ 推理估算 |

### 竞品格局关键结论

1. **百度文库绝对领先（MAU 3,400万+），但PPT只是其100+ AI功能之一**——意味着融资场景不会被它专门优化，这是我们的窗口。
2. **国际工具（Gamma等）在中国几乎零渗透**——语言、支付、合规障碍是长期壁垒，至少1-2年窗口期。
3. **国内纯AI PPT工具（AiPPT.cn）已跑通盈利**——证明赛道真实付费需求存在，"挣到钱了"。
4. **竞争已从「谁能生成PPT」转向「谁在特定场景生成更准的内容」**——场景深度是新入者的唯一机会。
5. **中国普通职场人年均87小时耗在PPT上，42%时间在排版和素材查找**——时间节省就是付费逻辑。

### 从竞品中学到的

| ✅ 借鉴 | ❌ 避免 |
|---------|--------|
| AiPPT.cn：4种生成方式（主题/文档/网址/脑图→PPT）灵活度高 | 百度文库：100+功能摊大饼，PPT深度不足 |
| Gamma：模块化设计+品牌控制，视觉一致性好 | Gamma：中文排版字距问题，全英文界面劝退 |
| iSlide：模板50万+，9年积累是壁垒 | WPS：套娃式收费被用户吐槽 |
| 百度文库：免费额度+邀请裂变，获客效率高 | 通用工具：缺乏场景化内容结构，用户生成后仍需大量修改 |

### MVP 聚焦用户

**聚焦：创业者（种子轮/A轮阶段）**

理由：
- 付费意愿最高（融资场景下 ¥200-500/年的工具费不值一提）
- 现有方案最弱（通用PPT工具无法解决融资叙事问题）
- 口碑传播效应强（创业者社群密集，成功案例易传播）
- 可触达（孵化器/加速器/创投媒体渠道明确）

> 李明是一个AI方向的创业者，下周要在36氪的Demo Day上做5分钟路演。他有一个5页的Word商业计划，但需要一份15页的Pitch Deck。他不是设计师，也不想花¥2000找PPT外包。

### 核心功能模块

#### A. 智能内容导入（输入→结构）

| 输入方式 | 处理 | 输出 |
|---------|------|------|
| 拖入Word/PDF/飞书文档 | 自动提取章节、关键数据、团队信息 | 结构化大纲 |
| 粘贴文本/大纲 | LLM 理解内容主题+逻辑 | 页面分配建议 |
| 输入关键词/一句话描述 | AI 生成完整大纲框架 | 10-15页内容骨架 |
| 语音口述（小程序） | ASR 转文字 → 提取要点 | 初稿大纲 |

#### B. Pitch Deck 专属引擎

| 模块 | 输入 | AI 处理 | 输出 |
|------|------|---------|------|
| 商业模式画布 | 业务描述 | 自动填充9宫格：价值主张/客户关系/收入来源/关键资源等 | 2页专业画布页 |
| 财务预测 | 现有数据/行业基准 | 生成3-5年收入预测+费用结构+关键假设 | 带图表的预测页 |
| 竞品分析 | 竞品名/领域 | 自动搜索公开信息+生成对比矩阵 | 2-3页竞品对比 |
| 估值逻辑 | 融资轮次/金额 | 推荐估值方法(对标/现金流)+生成逻辑说明 | 1页估值页 |
| 投资人视角检查 | 完整PPT | 检查逻辑链、数据完整性、视觉一致性、行业基准对比 | 修改建议清单 |

#### C. 设计引擎

- **智能排版**：根据内容密度自动调整版式（单栏/双栏/三栏）
- **自动配色**：根据行业+品牌色调推荐3套配色方案
- **统一字体**：全文档字体一致性检查+批量替换
- **图表自动匹配**：数据 → 推荐最佳图表类型（柱状/折线/饼图/雷达）

#### D. 协作与分发

- **分享链接**：生成可预览的在线链接（支持密码保护）
- **飞书/钉钉/企微集成**：一键分享到工作群
- **导出**：PPTX（可编辑）、PDF、图片集
- **版本管理**：自动保存历史版本，支持对比和回退

## 六、技术架构

### 技术选型

| 层 | 技术 | 理由 |
|----|------|------|
| 前端 | **Next.js + Tailwind CSS** | 全栈框架，SEO友好（后期做内容营销），生态成熟 |
| PPT渲染 | **PptxGenJS** (导出) + **自定义Canvas引擎** (预览) | PptxGenJS生成高保真PPTX；Canvas做在线预览编辑 |
| 后端 | **Python FastAPI** | AI pipeline用Python，API层轻量高效 |
| AI 模型 | **DeepSeek / 通义千问 API** | 国内合规、中文能力强、API成本可控（约¥0.5-2/次生成） |
| 文档解析 | **PyMuPDF + python-docx** | 成熟稳定的PDF/Word解析 |
| 图表生成 | **ECharts** (前端) + **Matplotlib** (后端兜底) | ECharts交互好；Matplotlib做服务端批量导出 |
| 数据库 | **PostgreSQL + Redis** | PG存结构化数据，Redis做模板缓存和会话 |
| 存储 | **阿里云OSS** | 用户上传文档+生成PPT存储 |
| 支付 | **微信支付 + 支付宝** | 中国用户唯一可行的支付方式 |
| 部署 | **阿里云/腾讯云** (国内服务器) | 数据合规要求，用户访问速度 |
| 登录 | **微信扫码 + 邮箱注册** | 降低注册门槛 |

### 数据流（简化）

```
用户上传文档
    │
    ▼
FastAPI 接收 → OSS 存储原始文件
    │
    ▼
PyMuPDF/python-docx 解析 → 提取文本/表格/图片元数据
    │
    ▼
LLM Prompt Chain：
  ① 内容提取和分类（问题/方案/市场/团队/财务）
  ② 每章节生成PPT内容（含建议图表类型）
  ③ 商业模式画布生成
  ④ 竞品分析（可选调用搜索API获取公开数据）
    │
    ▼
PptxGenJS / Canvas 渲染 → 在线预览
    │
    ▼
用户在线编辑 → WebSocket 实时保存
    │
    ▼
导出 PPTX/PDF → 生成下载链接
```

### AI 引擎设计（Prompt 链架构）

```
Prompt 1: 「内容提取」
  Input: 解析后的文档全文
  Output: JSON { 问题描述, 解决方案, 市场规模, 商业模式, 竞品列表, 团队, 财务数据, 融资需求 }
  Model: DeepSeek-V3, temp=0.3

Prompt 2: 「逐页生成」
  For each page in [封面, 问题, 方案, 市场, 产品, 商业模式(画布), 竞品, 营销, 团队, 财务(图表), 融资, 尾页]:
    Input: 该页对应的结构化数据 + 页模板描述
    Output: 标题 + 要点列表(3-5条) + 建议图表 + 排版建议
  Model: DeepSeek-V3, temp=0.5

Prompt 3: 「投资人视角检查（Phase 1 后期加入）」
  Input: 完整PPT内容
  Output: JSON { 逻辑问题[], 数据缺失[], 视觉建议[], 行业对标[] }
  Model: DeepSeek-V3, temp=0.2
```

## 十、风险与对策

| 风险 | 概率 | 影响 | 对策 |
|------|------|------|------|
| **百度文库加码融资PPT场景** | 🟡 中（30%） | 🔴 高 | 百度文库100+功能，融资PPT是小场景→在垂直场景建立心智深度（模板+数据+圈层） |
| **AiPPT.cn 等工具加入场景模板** | 🟡 中（40%） | 🟡 中 | 快速积累种子用户口碑，融资场景需要圈层信任（不是功能到位就行） |
| **创业者规模不及预期** | 🟢 低（20%） | 🟡 中 | MVP 验证后（M3）决定是否扩展场景 |
| **AI生成质量达不到「能拿钱」标准** | 🟡 中（35%） | 🔴 高 | Phase 1 定位为「大幅加速PPT制作」（80分+人工优化）而非「完全替代」 |
| **微信小程序审核** | 🟢 低（15%） | 🟡 中 | 先以 Web 版上线，小程序做补充；提前了解审核要求 |
| **用户对AI PPT付费意愿低于预期** | 🟢 低（25%） | 🔴 高 | AiPPT.cn 已盈利验证付费意愿存在；定价低于 WPS AI |

## 十一、待老板决策

| # | 决策项 | 建议 | 需拍板 |
