## 一、产品概述

### 一句话定位
**中国版 Luminar Neo——桌面端本地 AI 修图，照片永不上传。**

### 我们要解决的问题

| 问题 | 严重度 | 现有方案 | 我们的方案 |
|------|--------|----------|-----------|
| 中国没有桌面端「本地AI修图」产品——美图/醒图/轻颜全是云端处理，照片需上传 | 🔴 结构空白 | 美图秀秀（云端）/ Photoshop（太重/贵） | macOS原生本地AI修图，照片永不上传云端 |
| 证件照/合同照/私密照上传云端存在隐私风险 | 🟡 细分强需求 | 忍受云端/放弃修图 | 100%本地推理，隐私信任壁垒 |
| AI修图工具门槛高——SD/ControlNet 需手动安装Python/CUDA/模型 | 🟡 中等 | 放弃/找教程折腾 | 一键安装，开箱即用的本地AI修图 |
| 海外本地修图工具（Luminar Neo $119, Topaz $200/年）贵且无中文 | 🟡 中等 | 英语凑合用或不用 | ¥99买断，中文原生体验 |

### 核心差异化 vs 现有工具

| 维度 | Feather | 美图秀秀 | Luminar Neo | 醒图 |
|------|---------|---------|-------------|------|
| **处理位置** | ✅ 100%本地 | ❌ 云端为主 | ✅ 100%本地 | ❌ 云端为主 |
| **AI能力** | 🟢 本地AI修图（ControlNet+SD） | 🟢 云端AI（消除/变清晰等） | 🟢 本地AI（天空替换/降噪等） | 🟢 云端AI |
| **平台** | macOS 桌面 | 手机+Web | Win/Mac 桌面 | 手机 |
| **价格** | ¥99 买断 | ~¥144/年 | $119买断 / $9.99/月 | ~¥360/年 |
| **中文** | ✅ 原生中文 | ✅ | ⚠️ 有中文但非核心市场 | ✅ |
| **隐私** | 🔒 照片永不上传 | ⚠️ 云端处理 | 🔒 本地处理 | ⚠️ 云端为主 |
| **安装门槛** | ✅ 一键安装 | ✅ | ✅ | ✅ |

**一句话差异化**：桌面端本地AI修图 + 买断制 + 中国原生——目前在售产品中不存在这个组合。

## 二、市场与竞品（L 调研摘要）

### 市场体量

| 指标 | 数据 | 置信度 |
|------|------|--------|
| 全球修图软件市场 | 数十亿美元级别（Adobe PS+LR 数十亿收入为参照） | ⭐⭐⭐ |
| 本地AI修图细分 | 小众但存在真实需求——Luminar/MacPaw/Topaz均盈利 | ⭐⭐⭐ 竞品存活验证 |
| 中国 Mac 存量用户 | 2000-3000 万 | ⭐⭐⭐ |
| 可寻址用户（对隐私敏感+愿意付费的Mac修图用户） | **估算 50-100 万** | ⭐⭐ 推理估算 |

### 竞品格局关键结论

1. **中国市场存在明确的「桌面端本地AI修图」空白**——美图/醒图/轻颜全是云端，芯图相册是管理非修图。
2. **海外已有多款成熟的本地AI修图产品**（Luminar Neo、Topaz Photo AI、ACDSee 2026），证明技术可行且可商业化。
3. **隐私是「信任门槛」非「付费驱动」**——用户不会因为更隐私而多付费，但因为不信任而拒绝使用。
4. **仅19%用户愿意为AI功能付费**——不能只靠「AI修图」卖钱，必须靠「修图效果好+方便」。
5. **SD + ControlNet 技术上已覆盖80%修图需求**——从产品化角度看可行性高。

### 从竞品中学到的

| ✅ 借鉴 | ❌ 避免 |
|---------|--------|
| Luminar Neo：一键AI天空替换是杀手功能，口碑传播极强 | Topaz：从买断转订阅激怒老用户 |
| ACDSee：明确标注「no cloud-based AI processing」作为卖点 | 美图：部分功能云端/部分本地不透明，用户不知道什么上传了 |
| 简忆相册：$1.99 买断制极低定价吸引试水 | Adobe：订阅制入门门槛高，劝退轻度用户 |
| 芯图相册：本地AI照片管理12维度分类，切中隐私焦虑 | 美图：功能太多太重，AI修图只是100+功能之一 |

## 三、用户画像（L 调研提炼）

### Persona 对比总表

| Persona | 规模估计 | 核心场景 | 付费意愿 | 核心痛点 |
|---------|---------|----------|---------|---------|
| **注重隐私的摄影师/设计师** | 数万-数十万 | 客户照片/作品修图，不可外泄 | ⭐⭐⭐⭐⭐ 很高 | 云端修图违反合同保密条款 |
| **自媒体创作者** | 数百万 | 人像/产品图修图，需要快速+专业效果 | ⭐⭐⭐⭐ 高 | 手机修图效率低，桌面端缺乏好工具 |
| **企业用户（HR/行政）** | 数十万 | 证件照处理、合同扫描件修图 | ⭐⭐⭐⭐ 较高 | 员工敏感信息不能上传云端 |
| **隐私敏感型普通用户** | 数十万 | 家庭照片、私人照片修图 | ⭐⭐⭐ 中 | 不想照片被AI训练或泄露 |
| **数码极客/技术爱好者** | 数万 | 本地跑SD/ControlNet，追求可控性 | ⭐⭐⭐ 中 | 手动配置太麻烦，希望有封装好的产品 |

### MVP 聚焦用户

**聚焦1：注重隐私的摄影师/设计师（核心种子用户）**

理由：
- 隐私是硬需求（合同约束），不是偏好
- 付费意愿最高，单价承受力强
- 专业用户群体虽小但口碑传播力强（同行推荐）

**聚焦2：自媒体创作者（规模增长用户）**
- 用户基数大，付费意愿高
- 有持续的修图需求（日更/周更）
- 小红书/抖音/B站是天然传播渠道

### 关键场景（叙事化）

> 小林是独立摄影师，周末拍了一组客户的婚纱照（200张RAW），需要选30张精修。客户签字了保密协议——照片不能上传任何云端服务。
>
> 他打开Feather，导入200张照片。AI自动分组：按场景（户外/室内/特写）、按质量（清晰度评分）、按人物表情（闭眼/微笑筛选）。他快速筛选出50张候选。
>
> 然后批量应用「人像精修」预设：磨皮、瘦脸、大眼、美白一键完成——全部在本地 M1 Max 上运行，每张3秒。他对其中5张不满意，手动用「局部重绘」去掉了背景里的路人。
>
> 最后导出30张精修JPG+保留修图参数的.feather工程文件。全程断网也能用，照片从未离开过他的Mac。
>
> 他在摄影群里分享了效果图，有人问「什么软件」，他说「Feather，本地的不上传」，群里有5个人当天就下载了。

### 核心功能模块

#### A. AI 人像修图（核心杀手功能）

| 功能 | 输入 | AI 处理 | 输出 |
|------|------|---------|------|
| 一键美颜 | 人像照片 | 面部检测 → 磨皮/美白/瘦脸/大眼/祛痘/去黑眼圈 | 精修人像 |
| 背景替换 | 人像+背景选择 | ControlNet Canny 边缘检测 → 背景分割 → 新背景合成 | 换背景照片 |
| 路人消除 | 含路人照片 | Inpaint 局部重绘 → 内容感知填充 | 干净画面 |
| 证件照生成 | 正面照 | 背景白底替换+尺寸裁剪+标准排版 | 1寸/2寸证件照 |

#### B. AI 调色与滤镜

| 功能 | 输入 | AI 处理 | 输出 |
|------|------|---------|------|
| AI 自动调色 | RAW/JPG | 场景识别（逆光/夜景/人像/风景）→ 推荐调色参数 | 调色后照片 |
| 风格迁移 | 照片+风格参考 | IP-Adapter 风格提取+应用 | 风格化照片 |
| 批量调色 | 多张同场景照片 | 第一张调色参数→批量同步 | 统一风格组照 |

#### C. 智能照片管理

| 功能 | 说明 |
|------|------|
| AI 自动分类 | 按场景/人物/时间/质量自动分组 |
| 重复/相似照片检测 | 语义级相似检测，推荐保留最佳版本 |
| 质量评分 | AI评估清晰度/构图/曝光/表情，帮用户快速筛选 |
| 智能搜索 | 「上个月在海边拍的日落照片」→语义搜索 |

#### D. 隐私保护引擎

| 功能 | 说明 |
|------|------|
| **100%本地推理** | 所有AI处理在本地完成，使用Core ML / MLX加速 |
| **完全断网可用** | 不依赖网络，飞机上照样修图 |
| **零上传保证** | App沙盒隔离 + 网络权限透明 + 实时网络活动指示器 |
| **元数据脱敏** | 导出时可选择清除GPS/相机型号等EXIF信息 |

| **P0** | 模型一键下载 | App内下载所需SD模型（1-2GB） |
| **P1** | AI自动调色 | 场景识别→推荐调色 |
| **P1** | AI自动分类/质量评分 | 帮用户快速筛选 |

| **P2** | 风格迁移（IP-Adapter） | Phase 2 |
| **P2** | 证件照模式 | Phase 2 |
| **P2** | 智能搜索（「上个月的海边日落」） | Phase 2 |
| **P2** | 视频人像修图 | 不考虑（完全不同技术栈） |

### MVP 明确不做

| 不做 | 原因 | 何时做 |
|------|------|--------|
| Windows 版 | macOS优先验证PMF，单平台降低开发成本 | Phase 2/3 |
| 手机版 | 手机修图已是红海，桌面端是空白 | 不考虑 |
| 云端处理/备份 | 违反「本地隐私」核心定位 | 永不 |
| 图层/蒙版专业编辑 | 那是Photoshop的地盘，不是我们的用户 | 不考虑 |
| 团队协作/云端同步 | 与本地隐私定位矛盾 | 不考虑 |

## 六、技术架构

### 技术选型

| 层 | 技术 | 理由 |
|----|------|------|
| UI框架 | **SwiftUI** (macOS 14+) | Apple 原生，性能好，Mac App Store 上架标准 |
| 图像处理 | **Core Image + Metal** | Apple 原生硬件加速，无需额外依赖 |
| AI 推理 | **Core ML / MLX** | Apple Silicon 原生加速（ANE），本地推理首选 |
| 模型格式 | **Core ML (.mlmodelc)** + **GGUF** | Core ML 性能最优；GGUF 做模型分发 |
| SD 引擎 | **ml-stable-diffusion** (Apple 官方) | Apple 优化的 SD Swift 实现，支持 ControlNet |
| ControlNet | **ControlNet-MLX** 转 Core ML | 边缘检测/Inpaint/OpenPose/IP-Adapter |
| 面部检测 | **Vision.framework** | Apple 原生，零额外依赖 |
| 分发 | **Mac App Store + 官网 DMG** | MAS 覆盖主流用户，官网覆盖尝鲜/非MAS用户 |
| 支付 | **App Store IAP + 微信/支付宝（官网版）** | MAS版用IAP，官网版用微信/支付宝 |
| 模型分发 | **App内下载 + 可选模型包** | 基础包（1-2GB基础SD模型），高级包（额外ControlNet模型） |

### 数据流

```
用户导入照片（拖拽/打开/批量）
    │
    ▼
Core Image 解码 → 缩略图缓存
    │
    ▼
用户选择修图模式（人像精修/背景替换/消除/调色）
    │
    ▼
Vision.framework 面部检测 / ControlNet 推理 / Core Image 滤镜
    │ （全部在本地，使用ANE/GPU加速）
    ▼
实时预览（Metal 加速渲染）
    │
    ▼
用户确认 → 导出（Core Image 编码输出）
    │
    ▼
保存到用户指定位置（从未离开本地磁盘）
```

### AI 引擎设计

```
模型架构 (本地):
├── 基础 SD 模型（dreamshaper / realisticVision，转为 Core ML）
├── ControlNet 模块:
│   ├── Canny —— 边缘检测，用于背景替换、构图保持
│   ├── Inpaint —— 局部重绘，用于路人消除、瑕疵修复
│   ├── OpenPose —— 姿态检测，用于人像场景理解
│   └── IP-Adapter —— 风格迁移（Phase 2）
├── 面部检测：Vision.framework（Apple 原生，无需额外模型）
└── 调色：Core Image 原生滤镜 + 预设参数

推理策略:
- 优先使用 ANE（Apple Neural Engine）→ M1/M2/M3 加速
- 模型量化至 8-bit 减少内存占用
- 小图预推理 → 用户确认 → 全分辨率出图
- 8GB RAM Mac 可运行，16GB+ 体验流畅
```

## 七、商业模式

### 定价策略

| 层级 | 价格 | 目标用户 | 核心权益 | 预期占比 |
|------|------|---------|---------|---------|
| 免费版 | ¥0 | 试水用户 | 基础调色+5款滤镜，导出带水印，AI功能每日5次额度 | 70%用户 |
| Pro 买断 | **¥99 永久** | 核心用户（摄影师/自媒体/个人） | 全部AI功能+全部滤镜+无水印导出+智能管理+1年更新 | 25%用户 |
| Pro 订阅 | **¥9.9/月** | 需要持续更新+云同步的用户 | Pro全部 + 持续功能更新 + 新模型/滤镜持续推送 | 5%用户 |

**定价逻辑**：
- ¥99 买断对标 DaisyDisk（$9.99）和简忆相册（$1.99），在中国Mac工具中属于「合理低价」
- 远低于 Luminar Neo（$119 ≈ ¥860），但定位为「轻量替代」
- ¥9.9/月订阅对标美图秀秀粉钻SVIP（¥12/月），为「持续更新」需求提供选项
- 「买断制 + 本地处理」组合在中国修图市场没有竞品，是差异化卖点

### 收入模型（保守估计）

| 阶段 | 时间 | 下载量 | 付费用户 | 转化率 | ARPU | 收入（累计） |
|------|------|--------|---------|--------|------|-------------|
| M1 | 上线首月 | 1,000 | 150 | 15% | ¥99 | ¥14,850 |
| M3 | 第3个月 | 5,000 | 750 | 15% | ¥110 | ¥82,500 |
| M6 | 第6个月 | 15,000 | 2,250 | 15% | ¥115 | ¥258,750 |
| M12 | 第12个月 | 50,000 | 8,000 | 16% | ¥120 | ¥960,000 |

**关键假设**：
- Mac App Store 生产力工具付费转化率一般在10-20%，取15%
- 定价低（¥99）降低决策门槛，转化率可能高于大额工具
- M12 年收入 ¥96万——小而美的定位，一人公司足以维持

| 渠道 | 策略 | 预期贡献 |

## 十、风险与对策

| 风险 | 概率 | 影响 | 对策 |
|------|------|------|------|
| **Mac 修图用户太少** | 🟡 中（30%） | 🔴 高 | 2000-3000万Mac存量用户，按1%渗透率也有20-30万潜在用户；定价低降低试水门槛 |
| **美图推出本地版** | 🟡 中（25%） | 🟡 中 | 美图体型大，转向本地意味着放弃数据；建立「专业桌面端」定位与之错位 |
| **SD 开源协议风险** | 🟢 低（15%） | 🟡 中 | 使用开放授权的模型；Core ML 部署不违反GPL |
| **8GB Mac 性能不足** | 🟡 中（30%） | 🟡 中 | MVP 支持模型量化+小图预推理；明确标注推荐配置 |
| **用户对「本地」卖点不敏感** | 🟢 低（20%） | 🟡 中 | 以「效果+便利」为主卖点，「本地隐私」为辅卖点；ACDSee已验证「本地」是有效差异化 |
| **Mac App Store 审核** | 🟢 低（10%） | 🟡 中 | 沙盒合规，网络权限透明，无违规行为 |
