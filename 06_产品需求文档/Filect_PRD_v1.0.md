## 一、产品概述

### 一句话定位
**AI 原生 Mac 文件管家——语义去重 + 智能分类，存储焦虑终结者。**

### 我们要解决的问题

| 问题 | 严重度 | 现有方案 | 我们的方案 |
|------|--------|----------|-----------|
| Mac「其他」占用大，不知道什么可以删，怕删错 | 🔴 极痛 | CleanMyMac 智能扫描（基于规则） / DaisyDisk 可视化（手动） | AI 语义去重 + 智能分类，告诉你**哪些绝对安全可删、哪些建议保留** |
| 同一文件N个版本（合同v1/v2/终版/最终版/终极版）分不清哪个最新 | 🟡 中等 | Gemini 2（字节级去重）| **语义级去重**——不仅检测哈希相同，检测「内容含义相同」的不同版本 |
| 「上周修改的那个PDF在哪」找不到 | 🟡 频繁 | Spotlight 基础搜索 / Finder 手动翻 | NL搜索：「找到上个月修改的那个合同PDF」 |
| 大量素材/照片/下载堆积，磁盘满了才慌 | 🔴 极痛 | CleanMyMac（¥278/年） / 手动清理 | AI 自动分类+清理建议+存储预测，价格只要 ¥149/年 |

### 核心差异化 vs 现有工具

| 维度 | Filect | CleanMyMac | Gemini 2 | DaisyDisk |
|------|--------|-----------|----------|-----------|
| **去重深度** | 🔥 语义级（内容含义相同） | ⚠️ 基础（扫描垃圾） | ⚠️ 字节级（哈希+相似） | ❌ 无去重 |
| **AI能力** | ✅ AI语义去重+智能分类+NL搜索 | ⚠️ Smart Care（规则扫描） | ⚠️ 学习删除模式 | ❌ |
| **价格（年付）** | ¥149（≈$20） | ¥278（$39.95） | ¥139（$19.99） | ¥69（$9.99 买断） |
| **自然语言搜索** | ✅ 「找到上个月的合同」 | ❌ | ❌ | ❌ |
| **全功能一体** | ✅ 去重+分类+搜索+清理 | ✅ 全能（多维功能） | ⚠️ 纯去重 | ⚠️ 纯分析 |
| **设计/体验** | 🟢 现代原生SwiftUI | 🟢 精美 | 🟡 中等（3.7★） | 🟢 极佳可视化 |

**一句话差异化**：CleanMyMac 是「清洁工」，Filect 是「AI管家」——不仅帮你清理，更帮你**理解和管理**文件。

## 二、市场与竞品（L 调研摘要）

### 市场体量

| 指标 | 数据 | 置信度 |
|------|------|--------|
| 重复文件查找与删除工具全球市场（2024） | **$1.2B** | ⭐⭐⭐⭐ Cognitive Market Research |
| 预计2033年 | $3.6B（CAGR 12.8%） | ⭐⭐⭐ 预测 |
| PC清理软件市场（2024） | $2.5B → $3.2B (2029) | ⭐⭐⭐ MarketReportAnalytics |
| MacPaw 年收入（CleanMyMac+Gemini+Setapp等） | **$34.8M**（250人） | ⭐⭐⭐⭐ GetLatka |
| CleanMyMac 单品估算收入 | ~$20-25M | ⭐⭐⭐ 行业估算 |
| macOS 全球桌面份额 | ~15.7% | ⭐⭐⭐⭐ StatCounter |
| macOS 可寻址市场（去重+文件管理） | **$190M-$560M** | ⭐⭐⭐ 推理估算 |

**核心信号**：去重赛道增速（12.8% CAGR）显著快于PC清理大盘（5%），说明「智能去重」是增长最快且付费意愿最强的子方向。

### 竞品格局关键结论

1. **MacPaw $34.8M 年收入是赛道最大 proof**——仅靠 macOS 生态就能做出一家 250 人的公司。
2. **CleanMyMac 一家独大但正全面转型 AI-first（Eney助手）**——竞品窗口可能只有12-18个月。
3. **现有所有工具 AI 程度极低**——CleanMyMac 是规则扫描，Gemini 2 是简单ML，其他基本零 AI。AI 差异化窗口真实存在。
4. **CleanMyMac 持续涨价（2019→2025翻倍）导致用户流失**——给了新工具价格切入空间。
5. **中国 Mac 精品文件管理工具是空白**——腾讯柠檬清理免费但功能浅+有广告。

### 从竞品中学到的

| ✅ 借鉴 | ❌ 避免 |
|---------|--------|
| CleanMyMac：设计精美+一键操作+安全性（不自动删除，让用户确认） | CleanMyMac：价格逐年翻倍，用户反弹 |
| DaisyDisk：可视化磁盘地图是 killer feature，交互极佳 | Gemini 2：3.7★评分低，有误删风险报告 |
| BuhoCleaner：轻量+$29/年定价友好+终身买断选项 | CCleaner：安全事件+界面老旧+误删风险 |
| MacPaw 多产品矩阵：CleanMyMac养品牌 + Gemini养细分 + Setapp养分发 | 通用工具：纯规则扫描无法解决「不知道该不该删」的核心焦虑 |

## 三、用户画像（L 调研提炼）

### Persona 对比总表

| Persona | 规模估计 | 核心场景 | 付费意愿 | 核心痛点 |
|---------|---------|----------|---------|---------|
| **创意工作者**（设计师/摄影师/视频剪辑） | Mac用户中~25% | 大量素材重复/版本混乱/存储爆炸 | ⭐⭐⭐⭐⭐ 很高 | 文件太多分不清版本，删了怕丢、不删磁盘满 |
| **开发者/工程师** | Mac用户中~20% | node_modules/项目文件堆积/磁盘满 | ⭐⭐⭐ 中 | 知道问题但懒得手动清理 |
| **普通 Mac 用户** | 最大群体 | 存储不够用，不知道什么可以删 | ⭐⭐ 中低 | 「其他」占用大，怕删错 |
| **企业/团队** | 15% | 共享存储成本、合规留存 | ⭐⭐⭐⭐ 较高 | 存储成本持续增长 |
| **数字极简主义者** | 5% | 追求整洁、定期清理 | ⭐⭐⭐⭐⭐ 很高 | 愿意为工具付费，活跃在Setapp/Product Hunt |

### MVP 聚焦用户

**聚焦：创意工作者（设计师/摄影师/视频剪辑）**

理由：
- 文件管理需求最痛——海量素材、版本混乱、存储焦虑
- 付费意愿最高——存储满=停工，工具费 vs 时间/存储成本微不足道
- Mac用户占比最高——创意行业以Mac为绝对主力
- 口碑传播力——同行社群密集，好工具易传播
- 25% 的用户占比，单这个群体就足够支撑一个小而美的产品

### 关键场景（叙事化）

> 王是一名UI设计师，Mac上存了3年积累的设计源文件——Sketch/Figma/Framer/导出图/客户反馈截图，共500GB。磁盘红了。
>
> 他下载Filect。首次启动，AI花了2分钟扫描整个磁盘，然后呈现：
>
> **「发现3,427个重复/相似文件，可释放 87GB」**
> - 「app-design-v3.sketch」和「app-design-final.sketch」——内容几乎相同，建议保留最新的
> - 37个版本的「logo-export」PNG——AI推荐保留最高分辨率+透明背景的2个版本
> - 从微信下载的「合同照片」和扫描版的「合同PDF」——AI识别为同一内容，建议保留PDF
>
> **「78GB 的“可能不需要”文件」**
> - 6个月未打开的旧项目缓存 — 建议移到外置硬盘或删除
> - App自动下载的安装包 — 安全删除
> - iMessage 大附件缓存 — 可选清理
>
> 王花了10分钟审核，一键清理了120GB。然后他设置了「存储预测提醒」——AI告诉他按目前速度，2个月后会再次满，以及哪些文件类型增长最快。
>
> 他在设计师群里发了个截图：「救了我的命」，当天群里有8个人问是什么。

### 核心功能模块

#### A. AI 语义去重（核心差异化）

| 功能 | 传统工具 | Filect AI |
|------|---------|-----------|
| 字节级去重 | ✅ Gemini 2 / Duplicate File Finder | ✅ 基础支持 |
| 文件名相似检测 | ⚠️ Gemini 2 | ✅ |
| **内容语义去重** | ❌ | ✅ 「会议纪要v3.docx」和「Meeting Notes Final.pdf」识别为同一文档 |
| **多版本图像去重** | ❌ | ✅ 不同水印/分辨率/裁剪的同一照片识别为重复 |
| **跨格式去重** | ❌ | ✅ 同一张设计稿的Sketch源文件+导出PNG+导出JPG→推荐保留源文件 |
| 智能保留建议 | ❌ | ✅ AI根据版本新鲜度/分辨率/格式推荐最佳保留版本 |

#### B. AI 智能文件分类

| 分类维度 | 说明 | 示例 |
|---------|------|------|
| 按内容主题 | AI识别文件内容，自动分类 | 「合同」「发票」「设计稿」「照片」「代码项目」 |
| 按时间热度 | 最近修改/打开/创建时间 | 「本月活跃」「上月归档」「3个月前」「6个月+未使用」 |
| 按文件大小 | Top 100 大文件+增长趋势 | 「你最大的100个文件共占150GB」 |
| 按来源 | 文件来源App/路径 | 「微信下载」「浏览器下载」「邮件附件」「App缓存」 |
| 按可清理度 | AI评估安全删除等级 | 🟢 安全可删（缓存/安装包）/ 🟡 建议归档（旧项目）/ 🔴 建议保留（活跃文件） |

#### C. 自然语言搜索

| 搜索示例 | AI 理解 |
|---------|--------|
| 「找到上个月修改的那个合同」 | 文件类型=PDF/DOCX + 内容语义≈合同 + 修改时间=近30天 |
| 「王经理发我的那个报价单」 | 来源=邮件/微信 + 内容≈报价 + 涉及人物=王经理 |
| 「那个有蓝色logo的设计稿」 | 图像视觉embedding搜索 + 颜色=蓝色 + 内容≈logo |
| 「找到2025年所有发票」 | 内容=发票 + 时间=2025 + 结构化提取金额/日期 |

#### D. 清理引擎

| 功能 | 说明 |
|------|------|
| **一键清理建议** | 综合AI分析+安全等级，生成「安全清理清单」（用户审核后执行） |
| **磁盘可视化地图** | 对标DaisyDisk，用矩形树图展示磁盘占用（哪个文件夹/哪种文件类型最大） |
| **存储预测** | 学习用户存储增长趋势，预测何时满盘，提前预警 |
| **定期扫描报告** | 每周自动生成「存储健康报告」推送通知 |

## 六、技术架构

### 技术选型

| 层 | 技术 | 理由 |
|----|------|------|
| UI框架 | **SwiftUI** (macOS 14+) | Apple原生，MAS上架标准，DaisyDisk已验证交互可行性 |
| 文件系统访问 | **FileManager + Spotlight API** | Apple原生文件系统API + 元数据索引 |
| 磁盘可视化 | **自定义 Canvas / Swift Charts** | 矩形树图(treemap)交互，对标DaisyDisk |
| AI 推理 | **Core ML** (+ Apple Neural Engine) | 本地推理，隐私保护，低延迟 |
| 文本Embedding | **Core ML 部署 text-embedding 模型** (BGE-small/All-MiniLM) | 文档语义理解+去重判定 |
| 图像Embedding | **Core ML 部署 CLIP/MobileNet** | 图像内容理解+视觉搜索 |
| 文档解析 | **QuickLook + PDFKit + 内置Office解析** | macOS原生文档预览+文本提取 |
| 文字识别 | **Vision.framework OCR** | 图片型PDF/截图的文字提取 |
| 数据存储 | **SQLite** (本地) | 轻量，嵌入式，文件索引元数据 |
| 分发 | **Mac App Store + 官网 DMG** | 双渠道 |
| 支付 | **App Store IAP + 微信/支付宝（官网版）** | 双支付通道 |

### 数据流

```
首次启动：全盘扫描
    │
    ▼
FileManager 枚举文件 → 基础元数据（路径/大小/类型/修改时间）
    │
    ▼
过滤：跳过系统文件/隐藏文件/超小文件 → 聚焦用户文件
    │
    ▼
并行处理：
  ├── 哈希计算（SHA256）→ 字节级重复检测
  ├── 文件名相似度 → 疑似重复候选
  ├── Core ML 文本 Embedding → 文档语义理解（PDF/Office/txt/md）
  ├── Core ML 图像 Embedding → 图像内容理解
  └── Vision OCR → 图片型文档文字提取
    │
    ▼
SQLite 索引：文件元数据 + embedding向量 + 分类标签
    │
    ▼
AI 分析引擎：
  ① 语义去重：embedding 相似度 > 阈值 → 重复候选组
  ② 智能分类：内容主题/时间/来源/可清理度
  ③ 清理建议：综合评分 → 🟢🟡🔴
    │
    ▼
SwiftUI 呈现：可视化地图 + 分类 + 建议清单
    │
    ▼
用户审核 → 执行操作（删除/归档/保留）
    │
    ▼
增量扫描（监听文件系统变化）→ 更新索引
```

### AI 引擎设计

```
模型架构（全部本地 Core ML）:
├── 文本 Embedding 模型（~50-100MB）
│   → 文档/文件名语义理解
│   → 语义去重判定（cosine_similarity > 0.92 → 候选重复）
│   → NL搜索匹配
├── 图像 Embedding 模型（~30-80MB）
│   → 图像内容理解
│   → 相似图像检测
│   → 视觉搜索（Phase 2）
├── Vision.framework OCR
│   → 图片型文档文字提取
└── 分类器模型（~10MB）
    → 文件类型分类（合同/发票/设计稿/照片/代码/...）

推理策略:
- 优先使用 ANE（Apple Neural Engine）
- 扫描时批量并行推理，充分利用多核
- 增量更新：只对新文件/修改文件重新推理
- 索引持久化到 SQLite，重启无需重新扫描
- 首次全盘扫描预估时间：500GB磁盘约5-10分钟（M1+）
```

## 七、商业模式

### 定价策略

| 层级 | 价格 | 目标用户 | 核心权益 | 预期占比 |
|------|------|---------|---------|---------|
| 免费版 | ¥0 | 试水用户 | 扫描+可视化地图+字节级去重（不执行清理）+ 分类浏览 | 70%用户 |
| Pro 年度 | **¥149/年** | 核心用户 | 全部功能：语义去重+AI分类+NL搜索+清理执行+存储预测 | 25%用户 |
| 终身版 | **¥299 终身** | 重度用户/极简主义者 | Pro全部 + 终身更新 | 5%用户 |

**定价逻辑**：
- ¥149/年 ≈ $20/年，位于 Gemini 2（$19.99）和 BuhoCleaner（$29）之间
- 显著低于 CleanMyMac（$39.95/¥278），以「AI-native但更聚焦」定位竞争
- ¥299 终身版 — 对标 BuhoCleaner ¥399 终身 — 给「不想订阅」的用户一个出口，同时因「不含AI持续迭代」自然推动用户选订阅
- 中国定价 ¥99/年（vs 海外 $19.99/年），适配中国付费习惯

## 十、风险与对策

| 风险 | 概率 | 影响 | 对策 |
|------|------|------|------|
| **MacPaw全面转型AI-first，快速补齐AI能力** | 🟡 中（35%） | 🔴 高 | MacPaw体型大（250人），转型慢；我们先发2-3个小场景深度优化建立用户习惯 |
| **误删风险——用户信任一旦破裂无法修复** | 🟡 中（20%） | 🔴 极高 | 绝不允许自动删除；清理前展示详细对比预览；支持「移到废纸篓」而非永久删除；提供恢复指引 |
| **全盘扫描性能差（慢/卡顿）** | 🟡 中（25%） | 🟡 中 | 增量扫描优先；后台低优先级运行；首次扫描显示进度条+预估时间 |
| **清洁工赛道竞争固化——CleanMyMac品牌壁垒强** | 🟡 中（30%） | 🟡 中 | 不正面竞争「系统清理」，差异化在「AI去重+文件管理」——CleanMyMac是清洁工，我们是管家 |
| **macOS 系统权限收紧** | 🟢 低（15%） | 🟡 中 | 使用公开API；沙盒合规；提前了解新版本变更 |
| **Apple 可能在系统层面加入类似功能** | 🟢 低（15%） | 🔴 高 | AI语义去重不是系统功能，短期不会入系统；建立备份方案（跨平台扩展） |

## 十一、待老板决策

| # | 决策项 | 建议 | 需拍板 |
|---|--------|------|--------|
| 1 | **macOS 单平台 MVP？** | 是。MacPaw已验证纯macOS可做到$34.8M，先验证PMF | 同意/加Windows |
